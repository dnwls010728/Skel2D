# Skel2D 에디터 따라하기

화면 위쪽의 번호 버튼 다섯 개가 작업 순서입니다. 키보드 1~5로도 바꿀 수 있습니다.
**1 뼈대 → 2 이미지 → 3 메쉬 → 4 가중치 → 5 애니메이션.** 1~4단계는 리그 자체(셋업 포즈)를 만들고,
5단계는 시간에 따른 키를 기록합니다. 뷰포트 맨 위의 한 줄이 지금 무엇을 할 수 있는지 알려 주고,
되지 않는 버튼은 흐리게 표시되면서 바로 아래에 이유가 적힙니다.

> 이 문서 아래쪽의 그림(`01`~`08` PNG)은 이전 화면 배치입니다. 글을 기준으로 따라 하세요.

## 시작하기

새 파일(파일 > 새로 만들기)에는 `root` 본 하나만 있습니다. 화면 가운데 안내에서 **이미지 불러오기**를 누르거나
**예제 열기**로 예제를 열 수 있습니다. 파일 > 저장은 그림 파일이 있는 폴더 근처에 하세요
(그림 경로는 문서 기준 상대 경로로 저장됩니다).

## 1 뼈대

- 도구: **선택**(B), **새 본**(N), **이동**(V), **회전**(C), **크기**(X).
- 오른쪽 목록은 본 트리입니다. **root는 항상 맨 위에 있고 잠겨 있습니다.** 모든 본이 root 아래에 달리므로
  삭제·이름 변경·이동을 할 수 없습니다 (누르면 이유가 표시됩니다). 다른 본은 끌어서 부모를 바꿀 수 있지만
  부모 없이 둘 수는 없습니다.
- 새 본: 목록 위의 **새 본** 버튼은 선택한 본 아래(선택이 없으면 root 아래)에 본을 만듭니다.
  **새 본** 도구(N)로 뷰포트에서 끌어 그려도 됩니다. 끝점에서 이어 그리면 체인이 됩니다.
- 본을 고르면 아래 패널에서 위치·회전·크기·길이를 고칩니다. 같은 패널의 **목표 따라가기 (IK)**와
  **흔들림 (물리)** 그룹에 추가 버튼과 설명이 있습니다. 제약의 실행 순서는 목록 아래 **제약 실행 순서**에 있습니다.

## 2 이미지

- 목록 위의 **이미지 불러오기**(PNG/PSD) 버튼, 파일 > 이미지 가져오기, 또는 뷰포트에 파일을 끌어다 놓습니다.
  파일마다 슬롯이 하나 생깁니다. 슬롯은 본 위에서 그림 한 장을 보여 주는 자리입니다.
- 목록은 슬롯이 앞뒤 순서(위가 앞)대로 썸네일과 함께 나옵니다. 끌어서 순서를 바꿉니다.
- 슬롯을 고르면 패널에 **이 슬롯의 이미지**가 카드로 나옵니다 (썸네일, 이름, 종류: 그림 / 메쉬 / 공유 메쉬, **표시 중**).
  **이미지 추가**로 PNG를 여러 장 한꺼번에 이 슬롯에 더합니다 (눈 뜬/감은 모양, 입 모양 등). 파일 이름이 겹치면
  `_2`가 붙습니다. 카드의 **표시**는 그 이미지를 슬롯이 보여 줄 이미지로 지정하고, **더 보기**에서
  이름 변경·이미지 파일 교체·메쉬로 변환(3단계로 이동)·삭제를 합니다.
- 카드를 고르면 아래에 그 이미지의 위치·회전·크기 값이 나옵니다. **슬롯 설정**에서 본·색·앞뒤 순서를 바꿉니다.
- **의상 (스킨)** 그룹: 의상은 일부 슬롯의 이미지를 바꿔 끼우는 묶음입니다. **새 의상**으로 만들고 눈 버튼으로
  뷰포트에서 미리 봅니다. 슬롯 패널의 **스킨에 추가**로 선택한 슬롯 이미지를 의상에 복사합니다.
  어태치먼트(이미지) 이름은 카드의 **더 보기 > 이름 변경**이나 F2로 바꿉니다.

## 3 메쉬

- 맨 위에 "슬롯 › 이미지"가 표시됩니다. 아무것도 고르지 않았으면 메쉬가 될 수 있는 이미지 목록이 나옵니다.
- **그림**이면 "아직 메쉬가 아닙니다"라고 알려 주고 **메쉬 만들기**가 실시간 미리보기 대화상자를 엽니다
  (밀도·알파 임계값·패딩·디테일·내부 정점 방식·간격·오목 처리). **공유 메쉬**이면 부모 메쉬의 모양을 쓰므로
  **부모 메쉬로 이동** 버튼이 나옵니다.
- **메쉬**이면 정점·삼각형 수와 마우스 동작 네 가지가 설명과 함께 나옵니다: **이동**(정점 끌기),
  **추가**(이미지 안을 클릭해 정점 추가), **삭제**(정점 클릭으로 삭제), **접히는 선**(정점에서 정점으로 끌어 메쉬가
  접히는 선 지정; 주황색 선을 클릭하고 Delete로 제거). 뷰포트 우클릭으로 모드를 순환할 수도 있고, 뷰포트 위쪽 안내 줄도
  모드에 따라 바뀝니다. 청록색 굵은 선은 메쉬 외곽선, 흐린 선은 삼각형입니다. 동작 뒤에는 오른쪽 아래 알림에
  "정점 1개 추가됨 · Ctrl+Z로 취소" 같은 메시지가 나옵니다.
- **정점 자동 추가**, **다시 만들기**, **공유 메쉬 만들기**(스킨 대상과 이미지, 디폼 키 공유 여부를 고르는 대화상자).
  **고급**에는 UV 리셋 두 가지가 있습니다. 정점 추가·삭제 때 가중치와 디폼 키는 보존되고 새 정점은 이웃에서 보간합니다.
  디폼 키는 스킨마다 독립적으로 저장됩니다.

## 4 가중치

- 메쉬를 고르면 한 줄 상태가 나옵니다: "가중치 없음: 이미지 전체가 본 upper를 따라감" / "본 3개에 묶여 있습니다".
  메쉬가 아니면 "먼저 메쉬로 만드세요"와 **3단계로 이동해 메쉬 만들기** 버튼이 나옵니다.
- 맨 위 **자동으로 가중치 넣기**(이미지 기준; 대안으로 **거리 기준으로**)를 먼저 누르세요.
- 묶인 본 목록에는 막대와 % 숫자, **잠금** 버튼이 있습니다. 행을 누르면 그 본이 칠할 본이 되고 뷰포트에
  히트맵(파랑 0% ~ 빨강 100%, 범례 표시)이 나옵니다. **+ 본**으로 영향도 0인 본을 묶고,
  **선택 본 제거**는 재분배 방식을 고르는 미리보기 대화상자를 엽니다.
- 브러시: **추가 / 빼기 / 지정**, 크기·세기 슬라이더(값 표시). 드래그로 칠하고 Ctrl+드래그는 지웁니다.
- **결과 확인**: **본을 돌려 확인하기**를 켜거나 뷰포트에서 본을 Alt+드래그하면 임시로 돌려 이미지가 어떻게
  따라오는지 봅니다. 놓으면 원래대로 돌아오며 문서·Undo 기록은 바뀌지 않습니다.
- **정리와 복사**: 스무스, 복사/붙여넣기, 작은 가중치 정리…, 서로 바꾸기. **더 많은 도구**: 가중치 전송…, 미러….
  프루닝·미러·전송·본 제거는 옵션을 바꾸면 뷰포트에 즉시 반영하는 미리보기 대화상자이며 Enter/적용은 한 번의
  Undo로 기록하고 Escape/취소는 원본을 복원합니다.
- 잠금은 세션 설정이며 브러시·붙여넣기·스무스·프루닝·자동 가중치·미러·전송에서 그 본의 값을 보존합니다.
  Shift+클릭은 정점 선택, Ctrl+A / Escape는 전체/선택 해제, Ctrl+C / Ctrl+V는 가중치 복사/붙여넣기, [ / ]는 브러시 크기입니다.
  가중치 편집은 5단계에서는 할 수 없습니다 (이유가 표시됩니다).

## 5 애니메이션

- 오른쪽 목록 위쪽에서 애니메이션을 고르거나 **새 애니메이션**을 만듭니다 (아직 하나도 없으면 큰 버튼이 나옵니다).
  1~4단계에서 5단계로 돌아오면 마지막으로 편집하던 애니메이션이 다시 열립니다.
- 아래 타임라인에서 시간 막대를 옮기고 본을 움직이면 키가 기록됩니다 (자동 키가 꺼져 있으면 키 버튼이나 K).
  키 버튼은 모양과 글자로 상태를 말합니다: ◆ **키 있음**(빨강), ◇ **키**/**사이**(키 없음 / 다른 시간에 키 있음, 초록),
  ● **변경됨**(키로 기록하지 않음, 주황).
- **이미지 바꾸기가 눈 깜빡임과 립싱크의 전부입니다.** 슬롯을 고르면 패널에 이미지 카드가 나오고,
  카드를 누르면 지금 시간부터 그 이미지로 바뀌는 키가 만들어집니다 (**슬롯 숨기기** 카드 포함).
  눈 깜빡임: 눈 슬롯에 "뜬 눈"과 "감은 눈" 이미지를 넣고(2단계), 감을 시간에 감은 눈을, 바로 뒤에 뜬 눈을 누르세요.
- 타임라인의 **함께 재생할 애니메이션**에 다른 애니메이션을 더하면 작업하면서 겹쳐 재생해 볼 수 있습니다 (미리보기 전용).
- 물리·IK 제약을 만들었다면 뷰포트 위쪽의 **Pause / Reset / Off** 버튼으로 물리 미리보기를 조절합니다.

### 물리 제약 (M5)

뼈대가 애니메이션 포즈를 한 박자 늦게, 스프링처럼 따라 흔들리게 하는 제약입니다 (머리카락·천·꼬리·가슴·액세서리).

**만들기** 1단계에서 본을 선택하고 본 패널의 **흔들림 (물리)** 그룹에서 **흔들림 (물리) 추가**를 누르거나 본 우클릭 메뉴의
**물리 제약 추가**, Ctrl+K의 **새 물리 제약**을 사용합니다. 처음에는 회전만 영향을 받고 감쇠 0.9라서
적당히 흔들리다 멈춥니다. 선택한 본 아래로 자식이 하나씩 이어진 체인이면 **본마다 하나씩 만들기**로
체인 전체에 한 번에(Undo 한 번) 만들 수 있습니다.
제약은 IK와 한 목록에서 평가 순서대로 보이며 끌어서 순서를 바꾸고, F2로 이름을 바꾸고, Del로 지웁니다.
삭제 확인에는 지워지는 키·스킨 참조 수가 표시됩니다.

**인스펙터** 위에서부터 본, 순서, 영향(위치 X/Y·회전·크기·셰어, 0이면 그 속성은 흔들리지 않음), 프리셋입니다.
프리셋(머리카락·천·꼬리·가슴·액세서리)은 값 묶음을 한 번에 채울 뿐이며 이후 자유롭게 고칩니다.
**동작**(관성·강도·감쇠·질량), **환경**(바람·중력), **고급**(스텝 Hz·속도 제한·혼합)의 각 값 옆 **G**를
켜면 그 값은 **공유 값** 그룹의 전역 값을 읽습니다 (여러 제약을 한 번에 조절). 켜진 값은 읽기 전용으로
공유 값이 표시됩니다. **흔들어 보기**는 선택 제약에 충격을 줘 설정을 확인하는 미리보기이며 문서는 바뀌지 않습니다.

**5단계(애니메이션)**에서는 셋업 값을 몰래 바꾸지 않습니다. 동작·환경·혼합 값 앞의 키 버튼과 값 편집이
플레이헤드에 키를 찍고(빨강 = 여기 키, 초록 = 다른 시간에 키, 흐린 초록 = 키 없음), 본·영향·프리셋·G 같은
리그 설정은 1~4단계에서만 바꿉니다. **리셋 키**는 그 시간에 시뮬레이션을 다시 시작합니다.
도프시트의 **물리** 구역에 키 있는 속성별 행과 리셋 행이 보이고(이름이 비어 있는 전역 타임라인은
"모든 물리"), 키는 다른 키처럼 끌어 옮기고 복사하고 지울 수 있습니다. 질량 키에는 질량의 역수가 저장됩니다.

**미리보기 컨트롤** 뷰포트 위쪽에 문서에 물리 제약이 있을 때만 나타납니다.
**Pause**는 실시간 시뮬레이션을 멈추고, **Reset**(Shift+R)은 현재 포즈에서 다시 시작하며, **Off**는 물리 없이
애니메이션 포즈만 보여줍니다. 1~4단계에서는 **Physics preview**를 켜면 본을 끌거나 루트를 움직일 때 물리가
반응합니다 (기본 꺼짐). 정지 상태에서 플레이헤드를 앞뒤로 끌어도 처음부터 재생한 결과와 같습니다.
이 컨트롤들은 문서를 바꾸지 않습니다. 뷰포트에서 물리 본에는 작은 물결 표시가 붙고, 제약을 선택하면
영향 축 화살표가 나오며, 시뮬레이션이 애니메이션 포즈에서 벗어나 있으면 원래 위치가 흐린 고스트로 보입니다.

**스킨** 스킨 인스펙터의 *스킨 제약* 그룹에서 IK와 물리를 함께 켜고 끕니다 (그 스킨이 켜졌을 때만 적용).
Ctrl+K: 새 물리 제약, 물리 리셋/일시정지/끄기/셋업 미리보기, 흔들기. F1에도 정리되어 있습니다.
CLI/HTTP/MCP에서는 `pose`/`render`가 기본으로 시뮬레이션하며 `--physics none`, `--fps`, `--move`를 지원합니다
(`docs/AI_GUIDE.md`의 Physics 장).

## GIF 내보내기

**파일 > GIF 내보내기... (Ctrl+E)**로 현재 애니메이션을 반복 재생되는 GIF로 저장합니다. 내보낼 대상(애니메이션 / 셋업 포즈 / 모든 애니메이션), 스킨(미리 보는 스킨 / 스킨마다 한 파일), 저장 위치를 고르고 시간(FPS 최대 50, 무한 반복, 예열 등), 크기, 색, 표시 그룹을 조절한 뒤 **내보내기**를 누릅니다. 마지막 프레임 포함은 반복 애니메이션이면 꺼 두세요. GIF 픽셀은 불투명 아니면 투명뿐이라 투명 배경에서는 가장자리가 배경색과 섞이므로, 배경색을 올려 둘 페이지 색에 가깝게 고르세요. **Ctrl+Shift+E**는 마지막 설정으로 바로 다시 내보냅니다. 함께 재생할 애니메이션과 미리 보는 스킨이 GIF에 그대로 들어가며, 내보내기는 백그라운드에서 진행됩니다. 오른쪽 위 진행 창에 파일 이름과 진행률이 나오며 취소할 수 있습니다. 완료·실패·취소 결과는 오른쪽 아래 알림에 나옵니다. 상태바에는 단축키 안내, 선택 정보, 확대 비율이 남습니다. 명령줄: `skel2d gif 파일 -o out.gif --anim walk --gif-fps 25 --fit 400x400`. 자세한 설명은 PDF 사용설명서(`Skel2D_사용설명서.pdf`) 8장에 있습니다.

## PDF 사용설명서 만들기

`Skel2D_사용설명서.pdf`는 `docs/manual/pdf/manual.html` (A4 인쇄용 HTML, CSS 포함, 그림은 `pdf/img`)에서 만듭니다.
`scripts/make_dist.ps1`이 이 PDF를 배포본에 `Skel2D_Manual_ko.pdf`로 넣습니다.

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf="E:\Projects\Skel2D\docs\manual\Skel2D_사용설명서.pdf" "file:///E:/Projects/Skel2D/docs/manual/pdf/manual.html"
```

- 목차와 "이럴 때" 표의 쪽 번호는 HTML에 직접 적혀 있습니다. 내용을 고쳐 쪽이 바뀌면 PDF를 다시 만든 뒤 번호를 맞추세요. 목차 링크는 쪽 번호와 상관없이 동작합니다.
- 화면 그림 `pdf/img/m_*.png`는 버전 0.2.0 에디터에서 `skel2d-editor FILE --lang ko --step N --wait 5 --screenshot OUT.png`로 찍은 것을 잘라 쓴 것입니다. UI가 바뀌면 다시 찍으세요.
- 버전 0.2.0 기준입니다. 표지의 버전 글자는 `manual.html`의 `.cover`에 있습니다.
