PART 1

처음 5분

Skel2D는 무엇인가요

그림에 뼈를 심어 움직이게 만드는 2D 애니메이션 에디터입니다.

포토샵 PSD를 바로 불러올 수 있습니다.

작업 결과는 사람이 읽을 수 있는 .skel.json 파일로 저장됩니다. GIF와 스프라이트 시트로도 내보냅니다.

프로그램하는 일
skel2d-editor.exe마우스로 작업하는 에디터입니다. 이 설명서는 대부분 이 프로그램 이야기입니다.
skel2d.exe명령줄 도구입니다. 렌더링, 내보내기, AI 연동에 씁니다. 처음에는 몰라도 됩니다 (부록 A).

설치하고 실행하려면

설치 프로그램은 없습니다. 압축을 풀면 바로 실행됩니다.

  1. Skel2D-버전-win64.zip을 마우스 오른쪽 버튼으로 눌러 모두 압축 풀기를 고릅니다.Skel2D-버전-win64 폴더가 만들어집니다. 바탕화면이나 문서 폴더처럼 쓰기 가능한 곳에 푸세요.
  2. 폴더 안의 skel2d-editor.exe를 더블클릭합니다.어두운 창이 뜨고 위쪽에 1 뼈대부터 5 애니메이션까지 버튼 다섯 개가 보입니다.
zip 안에서 바로 실행하지 마세요예제 그림을 찾지 못할 수 있습니다. 꼭 압축을 풀고 실행하세요.
Windows가 "PC 보호" 창을 띄우면이 프로그램은 코드 서명이 없어서 처음에 경고가 나올 수 있습니다. 악성 프로그램이라는 뜻이 아닙니다.
추가 정보를 누르고 실행을 누르세요. 같은 파일은 다음부터 뜨지 않습니다.

예제를 열어 보려면

처음에는 만들어진 예제를 열어서 움직이는 모습을 봅니다.

  1. 에디터를 켜면 가운데에 여기서 시작하세요 안내가 나옵니다. 예제 열기를 누릅니다.파일 선택 창이 열립니다. .skel.json 파일을 창에 끌어다 놓아도 됩니다.
  2. examples\rig\character.skel.json을 고릅니다.소년 그림과 노란 뼈대가 나타납니다.
  3. 위쪽 5 애니메이션 버튼을 누르고, 오른쪽 목록에서 wave를 누릅니다.뷰포트 둘레가 붉게 바뀝니다. 아래에 타임라인이 나타납니다.

화면 한 장으로 보기

5단계 화면입니다. 번호는 아래 설명과 같습니다.

1 2 3 4 5 6 7 8 9
  1. 메뉴: 파일, 편집, 보기. 열기, 저장, 내보내기가 여기 있습니다.
  2. 명령 검색 Ctrl+K, 언어, 도움말 (F1). 메뉴 위치를 모를 때 가장 빠릅니다.
  3. 단계 버튼 1 뼈대 ~ 5 애니메이션. 키보드 1~5로도 바꿉니다.
  4. 도구. 단계마다 목록이 달라집니다.
  5. 뷰포트. 그림과 뼈를 보고 만지는 곳입니다. 맨 위 한 줄은 지금 할 수 있는 일을 알려 줍니다.
  6. 목록. 단계마다 본, 슬롯, 메쉬, 애니메이션이 나옵니다.
  7. 속성 패널. 고른 항목의 값을 고칩니다. 안 되는 버튼은 흐리게 보이고 이유가 적힙니다.
  8. 타임라인 (5단계). 시간과 키를 다룹니다. 재생 옆 자동 키가 여기 있습니다.
  9. 상태 표시줄. 단축키 힌트, 선택 정보, 확대 비율.

5단계에서는 뷰포트 둘레가 붉은 테두리로 바뀌고, 왼쪽 위에 애니메이션 이름과 시간이 나옵니다. 저장·오류 알림은 오른쪽 아래에 나오고, 창이 열려 있는 동안에는 왼쪽 아래로 옮겨 갑니다.

알아 둘 말 여섯 개

이 여섯 가지만 알면 나머지는 따라옵니다.

본 (Bone)그림이 매달릴 뼈입니다. 부모가 움직이면 자식도 따라 움직입니다. 맨 위에 root가 있습니다.
슬롯 (Slot)본 위의 그림 걸이입니다. 앞뒤 순서가 있고, 한 번에 이미지 한 장을 보여 줍니다.
이미지: 그림과 메쉬그림은 직사각형 한 장입니다. 메쉬는 삼각형으로 나눈 그림이라 고무처럼 휘어집니다.
가중치 (Weight)메쉬의 점이 어느 본을 얼마나 따라가는지 정한 비율입니다. 점마다 합이 100%입니다.
셋업 포즈애니메이션이 없을 때의 기본 자세입니다. 1~4단계는 이 자세를 만듭니다.
키 (Key)"이 시간에 이 값"을 적은 점입니다. 키 사이는 프로그램이 채웁니다. 5단계에서 찍습니다.

작업은 다섯 단계입니다

1 뼈대관절에 본을 심는다
2 이미지그림을 불러온다
3 메쉬구부러질 그림을 메쉬로
4 가중치어느 본이 어디를 움직일지
5 애니메이션시간에 따라 키를 찍는다

1~4단계는 캐릭터의 설계(리그)를 만들고, 5단계에서 움직임을 만듭니다. 5단계 값은 셋업 포즈와의 차이로 저장됩니다. 그래서 나중에 셋업을 고쳐도 애니메이션이 대체로 유지됩니다.

PART 2

튜토리얼: 그림에서 움직이는 캐릭터까지

소년 그림 한 장에 뼈를 심고, 손을 흔들게 만듭니다.

재료는 examples\rig\character.png 한 장입니다. 30분 정도 걸립니다.

완성본은 examples\rig\character.skel.json입니다. 막히면 열어서 비교하세요.

준비새 문서와 저장
A이미지 불러오기
B뼈대 그리기
C메쉬 만들기
D가중치 넣기
E손 흔들기

준비

  1. 작업 폴더를 만들고(예: 문서\hero) examples\rig\character.png를 복사해 넣습니다.1086 x 1448 픽셀 그림이 작업 폴더에 있습니다.
  2. 에디터에서 파일 > 새로 만들기를 누릅니다.여기서 시작하세요 안내가 나오고, 목록에 root 하나만 있습니다.
  3. 파일 > 다른 이름으로 저장...으로 작업 폴더에 hero.skel.json으로 저장합니다.저장 알림이 나옵니다.
왜 먼저 저장하나요그림 경로는 문서 파일 기준 상대 경로로 저장됩니다. 문서와 그림을 같은 폴더에 두면 폴더째 옮겨도 그림을 잃지 않습니다.

A이미지를 불러오려면

먼저 그림을 불러옵니다. 그림이 보여야 관절 위치를 맞출 수 있습니다.

  1. 2를 누르거나 2 이미지 버튼을 누릅니다.오른쪽 위에 파란 이미지 불러오기 버튼이 나옵니다.
  2. 이미지 불러오기를 누르고 character.png를 고릅니다. 탐색기에서 뷰포트로 끌어다 놓아도 됩니다.소년이 나타나고 목록에 슬롯 character가 생깁니다.
  3. 목록에서 character를 누릅니다.보이는 부분의 윤곽선이 파랗게 표시되고, 이미지 상자는 더 흐리게 표시됩니다.
  4. Shift+F로 전체가 보이게 맞춘 뒤 Ctrl+S로 저장합니다.

그림 위치가 원점 근처에서 어긋나 보여도 괜찮습니다. 이후 뼈를 그림 위에 그립니다.

B뼈대를 그리려면

관절이 꺾이는 곳에 본을 심습니다. 몸통에서 바깥쪽으로, 척추 다음에 팔다리 순서로 그립니다.

  1. 1을 누르고 도구에서 새 본 (N)을 고릅니다.맨 위 안내 줄이 "뷰포트에서 끌어 본을 그립니다"로 바뀝니다.
  2. 골반에서 가슴까지 위로 끌어서 본을 그립니다. 오른쪽 아래 패널의 이름 칸에서 hip으로 바꾸고 Enter를 누릅니다.트리의 root 아래에 hip이 나타납니다.
  3. hip 끝에서 이어서 끌어 chest를, chest 끝에서 이어서 head를 그립니다.끝점에서 시작하면 부모-자식 체인이 됩니다.
  4. 선택 (B)으로 chest를 누르고 새 본 (N)으로 돌아와, 어깨에서 팔꿈치까지 upper_arm_l, 팔꿈치에서 손목까지 forearm_l, 손끝까지 hand_l을 그립니다.선택한 본이 새 본의 부모가 됩니다.
  5. chest를 다시 고르고 반대쪽 팔 upper_arm_r, forearm_r, hand_r을 그립니다.
  6. hip을 고르고 다리를 그립니다. thigh_l, shin_l, foot_l, 그리고 반대쪽 thigh_r, shin_r, foot_r.그림 위에 노란 본이 사람 모양으로 놓입니다.
  7. Ctrl+S로 저장합니다.
본 이름과 계층몸통: root > hip > chest > head
팔 (l, r): chest > upper_arm > forearm > hand
다리 (l, r): hip > thigh > shin > foot

_l은 캐릭터의 왼쪽이고 화면에서는 오른쪽에 있습니다. 잘못 그렸으면 Ctrl+Z로 되돌리거나, 선택 도구로 본을 끌어 옮기세요.

C메쉬를 만들려면

지금 그림은 직사각형이라 통째로 root만 따라갑니다. 팔다리가 따로 움직이도록 메쉬로 바꿉니다.

  1. 3을 누르고 목록에서 character를 누릅니다."아직 메쉬가 아닙니다"와 메쉬 만들기 버튼이 보입니다.
  2. 메쉬 만들기를 누릅니다.대화상자가 열리고, 뷰포트에 바로 미리보기가 나옵니다.
  3. 밀도는 보통 그대로 둡니다. 값을 바꾸면 뷰포트가 즉시 바뀝니다.
  4. 적용 버튼이나 Enter로 확정합니다. 취소는 Esc입니다.그림 위에 청록색 외곽선과 점이 생깁니다.
점은 많을수록 좋을까요?많으면 부드럽게 휘지만 가중치 작업이 늘어납니다. 어깨, 팔꿈치, 무릎처럼 구부러지는 곳에만 점이 모여 있으면 충분합니다. 정점을 직접 고치는 방법은 3-5를 보세요.

D가중치를 넣으려면

메쉬의 점마다 "어느 본을 얼마나 따라갈지"를 정합니다. 먼저 자동으로 넣고, 어색한 곳만 고칩니다.

  1. 4를 누르고 목록에서 character를 누릅니다."가중치 없음"이라는 한 줄과 자동으로 가중치 넣기 버튼이 보입니다.
  2. 자동으로 가중치 넣기를 누릅니다."본 15개에 묶여 있습니다"로 바뀝니다.
  3. 뷰포트에서 본을 눌러 보세요.그 본의 영향이 파랑(0%)에서 빨강(100%)까지 색으로 보입니다.
  4. 본을 돌려 확인하기를 켜고 팔 본을 돌려 봅니다. 켜지 않고 Alt를 누른 채 본을 끌어도 됩니다.그림이 본을 따라 구부러집니다. 놓으면 원래대로 돌아오고 문서는 바뀌지 않습니다.
  5. 어색한 곳은 그 본을 목록에서 고르고 브러시로 칠합니다. Ctrl+드래그는 지우기, [ ]는 브러시 크기입니다.
  6. Ctrl+S로 저장합니다.
가중치 편집은 5단계에서는 안 됩니다1~4단계에서만 고칠 수 있습니다. 5단계에서 어깨가 구겨져 보이면 4단계로 돌아가 고치세요.

E손 흔들기 애니메이션을 만들려면

1초짜리 반복 애니메이션 wave를 만듭니다. 0초에 팔을 내리고, 0.5초에 올리고, 1초에 다시 내립니다.

  1. 5를 누르고 새 애니메이션을 누릅니다. 이름 wave, 길이(초) 1로 생성합니다.뷰포트 둘레가 붉어지고, 왼쪽 위에 "wave · 0.00s"와 자동 키: 켜짐이 나옵니다.
  2. 트리에서 upper_arm_l을 고르고, 시간 0에서 K를 누릅니다.타임라인 0초에 마름모가 생깁니다.
  3. 시간 칸에 0.5를 입력합니다.시간 막대가 0.5초로 옵니다.

  4. 본을 돌려 확인하기를 켜거나 Alt+드래그로 본을 돌려 봅니다. 놓으면 원래대로 돌아오고 문서는 바뀌지 않습니다.

+ 본은 영향이 0인 본을 묶습니다. 선택 본 제거는 가중치를 누구에게 넘길지(재분배: 자동 / 가장 가까운 본 / 부모) 고르는 창을 엽니다.

정리하고 복사하는 도구

기능설명
스무스이웃과 섞어 거친 경계를 풉니다. 다시 누르면 더 넓게 퍼집니다.
복사 / 붙여넣기고른 정점의 평균 가중치를 다른 정점에 적용합니다 (Ctrl+C / Ctrl+V).
작은 가중치 정리…아주 작은 영향을 없애고 점당 본 수를 제한합니다 (점마다 본 개수 (최대), 이 값 미만 제거).
서로 바꾸기칠하는 본과 고른 본의 가중치를 맞바꿉니다.
가중치 전송…다른 메쉬(몸 위의 옷 등)에서 가장 가까운 점의 가중치를 복사합니다.
미러…한쪽 가중치를 반대쪽으로 복사합니다. 본 이름의 _l/_r, left/right, L_/R_를 서로 바꿉니다.
가중치 정규화각 점의 합을 100%로 맞춥니다.
미리보기 창은 같은 방식입니다스무스, 정리, 미러, 전송, 본 제거는 값을 바꾸면 뷰포트에 즉시 반영됩니다. Enter/적용은 실행 취소 한 번으로 기록되고 Esc/취소는 원본을 복원합니다.
  • 잠금을 켠 본은 브러시, 붙여넣기, 스무스, 정리, 자동 가중치, 미러, 전송이 건드리지 않습니다. 잠금은 작업 중 설정이며 저장되지 않습니다.
  • 정점 선택: Shift+클릭, Ctrl+A(전체), Esc(해제). 선택하면 브러시는 그 정점에만 닿습니다.
  • 가중치 편집은 5단계에서는 할 수 없습니다.

3-7클리핑을 쓰려면

포토샵의 클리핑 마스크처럼, 슬롯을 다른 슬롯의 그림 안에서만 보이게 합니다. 두 슬롯은 각자 움직입니다. 병 속에서 출렁이는 액체가 좋은 예입니다.

클리핑 걸기

  1. 2 이미지에서 클리핑할 슬롯(예: liquid)을 누릅니다.
  2. 패널 맨 위 클리핑 구역에서 ○○에 클리핑을 누릅니다.바로 뒤 슬롯이 베이스가 됩니다. 이미지가 베이스 안에서만 보입니다.
  3. 다른 슬롯을 베이스로 하려면 다른 슬롯에 클리핑에서 고릅니다.
  4. 풀려면 클리핑 해제를 누릅니다.

다른 방법: 슬롯의 오른쪽 버튼 메뉴(목록과 뷰포트 모두), Ctrl+Alt+G, Ctrl+K 명령 검색의 선택한 슬롯 클리핑 또는 해제.

규칙

한 단계만클리핑된 슬롯은 베이스가 될 수 없고, 베이스는 클리핑될 수 없습니다.
베이스가 사라지면베이스를 숨기거나 투명하게 하면 클리핑된 슬롯도 사라집니다.
그리기 순서는 따로클리핑과 앞뒤 순서는 별개입니다. 순서를 바꿔도 클리핑은 그대로 유지됩니다.
표시목록에서 클리핑된 슬롯에는 클립 아이콘이 붙습니다.
내보내기PNG, GIF, 스프라이트 시트에 클리핑이 그대로 반영됩니다.
PSD에서레이어마다, 클리핑 유지로 가져오면 자동으로 클리핑됩니다.

예제: examples\clipping (물약 병). 액체는 곱하기, 반짝임은 스크린 블렌드이고 둘 다 병에 클리핑되어 있습니다. 애니메이션은 slosh, shine, idle입니다.

3-8애니메이션을 만들고 키를 찍으려면

애니메이션 만들기

  1. 5 애니메이션에서 새 애니메이션을 누릅니다.
  2. 이름, 길이(초), FPS를 정하고 생성합니다.현재 애니메이션을 복제하려면 현재 애니메이션 복제. 목록에서 오른쪽 버튼으로 이름 변경, 삭제.
  3. 목록의 이름을 누르면 편집이 시작되고, 다시 누르면 셋업 포즈로 돌아갑니다.

자동 키

타임라인 위쪽 재생 옆의 자동 키 버튼입니다. 기본은 켜짐이고 켜면 빨갛게 보입니다. 5단계에서 R로도 켜고 끕니다. 뷰포트 왼쪽 위에도 상태가 나옵니다.

자동 키동작
켜짐시간 막대를 옮기고 본을 움직이거나 값을 바꾸면 그 시간에 바로 키가 기록됩니다.
꺼짐변경은 키 없이 남습니다(주황색). K나 키 버튼으로 찍어야 하고, 찍지 않고 시간 막대를 옮기면 알림과 함께 버려집니다.

키 버튼의 모양

모양뜻
빨간 채운 마름모 키 있음이 시간에 키가 있습니다.
빈 마름모 키 / 사이키는 키 없음, 사이(점 있는 마름모)는 다른 시간에 키가 있어 값이 보간 중입니다.
주황 채운 원 변경됨바꿨지만 키로 기록하지 않았습니다.

K는 선택한 본에 키를 찍습니다(바꾼 속성만). 보이는 모든 행에 찍으려면 Ctrl+Shift+L입니다.

타임라인 읽는 법

  • 시간 칸(초)과 프레임 칸에 숫자를 쓰고 Enter로 이동합니다. , .는 한 프레임, Home End는 처음과 끝입니다.
  • 모든 행을 끄면 선택한 본과 관련된 행만 보입니다. 개요 행은 모든 키의 요약이고, 행 왼쪽 화살표로 속성별로 펼칩니다.
  • 키를 끌면 시간이 이동합니다 (Alt 스냅 해제, Ctrl+Shift 복사). 더블클릭하면 삭제, Ctrl+A는 전체 선택, Del은 삭제입니다.

키 사이를 다듬으려면: 보간

키를 고르면 오른쪽에 보간 그래프가 나옵니다. 이 키에서 다음 키까지 값이 변하는 방식을 고릅니다.

선형일정한 속도.
계단다음 키에서 갑자기 바뀝니다.
천천히 시작 / 천천히 끝 / 천천히 시작/끝가속하거나 감속합니다. 걷기 같은 반복 동작은 시작과 끝을 부드럽게 하면 자연스럽습니다.
베지어그래프의 두 점을 끌어 직접 모양을 만듭니다.

이미지를 바꾸려면 (눈 깜빡임, 입 모양)

  1. 2단계에서 눈 슬롯에 이미지 추가로 "뜬 눈"과 "감은 눈"을 넣어 둡니다.
  2. 5단계에서 슬롯을 고르면 이미지 카드가 나옵니다. 감을 시간에 "감은 눈" 카드를, 바로 뒤에 "뜬 눈" 카드를 누릅니다.카드를 누르면 그 시간부터 그 이미지로 바뀌는 키가 만들어집니다. 슬롯 숨기기 카드도 있습니다.

슬롯의 색조(알파)도 키로 기록해 페이드를 만들 수 있습니다.

알아 두면 편한 기능

기능하려면
함께 재생할 애니메이션타임라인 위 애니메이션 추가로 다른 애니메이션을 겹쳐 봅니다 (미리보기 전용). 아래부터 적용되고, 끌어서 순서를, 체크로 켜고 끄기를, 슬라이더로 불투명도를 바꿉니다. 겹쳐 둔 레이어는 내보내기에도 들어갑니다.
표정 포즈시간 0에 키 하나만 찍은 애니메이션(예: face/happy)을 겹쳐서 표정으로 씁니다. 이미지 키에서 (아래 트랙 / 셋업)을 고르면 아래 레이어의 이미지로 돌아갑니다.
그리기 순서타임라인의 그리기 순서 구역에서 슬롯 옆 위/아래 화살표로 한 칸씩 옮기면 이 시간에 키가 기록됩니다. 셋업 순서는 원래 순서로 되돌리는 키, 키 삭제는 이 시간의 키를 지웁니다.
이벤트발소리처럼 게임에 알리는 순간입니다. 이벤트 구역에서 이벤트 추가…로 이름과 값(정수, 소수, 문자열)을 정하고, 고른 뒤 재생 헤드에 키를 누릅니다.
어니언 스킨왼쪽 어니언 스킨 (O)을 켜면 앞뒤 프레임이 흐리게 겹쳐 보입니다.

3-9스킨(의상)을 바꾸려면

같은 뼈대와 애니메이션을 두고 일부 슬롯의 그림만 바꿔 끼웁니다. 이 안내는 examples\skins를 씁니다. 의상 세 벌(knight, mage, ranger)과 애니메이션 idle, walk, wave가 있습니다.

원리: 이름표(플레이스홀더)슬롯 torso에는 "torso"라는 이름표만 있고, knight 의상은 이 이름표에 갑옷 그림을, mage 의상은 로브 그림을 지정합니다. 이름표 이름은 모든 의상에서 같아야 합니다. 그래서 이미지 키도 의상이 바뀌어도 작동합니다.

의상 미리 보기

  1. 예제를 열고 2 이미지로 갑니다. 아래쪽 의상 (스킨) 그룹이 있습니다.
  2. knight 줄의 눈 버튼을 누릅니다.뷰포트에 갑옷 기사가 나타납니다.
  3. knight를 끄고 mage를 켭니다.마법사로 바뀝니다. 여러 의상을 동시에 켜면 나중에 켠 것이 우선합니다.
  4. 5 애니메이션에서 walk를 재생합니다.같은 동작을 의상만 바꿔 합니다.

새 의상 만들기

  1. 의상 (스킨) 그룹에서 새 의상을 누르고 이름(예: pirate)을 정해 생성합니다.미리보기 스킨에서 복사로 켜 둔 의상에서 시작할 수도 있습니다.
  2. pirate의 눈 버튼을 켭니다. 이후 편집은 이 의상에 적용됩니다.
  3. 슬롯(예: hat)을 고르고 스킨에 추가를 누릅니다.보이는 이미지가 같은 이름표로 pirate에 복사됩니다.
  4. 이미지 카드 더 보기 > 이미지 파일 교체...로 해적 모자 PNG를 고릅니다.knight와 mage는 그대로입니다.
  5. 다른 슬롯도 반복합니다. 바꾸지 않은 슬롯은 기본 그림이 보입니다.
  • 모양이 같은 옷이라면 공유 메쉬 만들기로 가중치를 한 번만 칠하고 의상마다 다른 그림을 씁니다. Ctrl+K의 스킨 비교로 빠진 이름표를 찾습니다.
  • 스킨 인스펙터의 스킨 본은 그 의상이 켜졌을 때만 동작하는 본(예: 망토)이고, 스킨 제약은 IK와 물리를 의상별로 켜고 끕니다.
  • 의상별 GIF는 내보내기에서 스킨마다 한 파일을 고릅니다.

3-10팔다리를 목표에 맞추려면: IK

IK는 손(목표)을 놓으면 팔이 알아서 굽혀집니다. 발을 땅에 붙인 채 몸만 움직일 때 씁니다.

IK 만들기

  1. 1 뼈대에서 팔다리의 끝 본(예: shin_l)을 고릅니다.
  2. 본 패널의 목표 따라가기 (IK) 그룹에서 목표 따라가기 (IK) 추가를 누릅니다.끝에 <본이름>_target 본과 IK 제약이 생깁니다. 선택한 본과 부모 본, 두 개가 한 팔다리로 묶입니다.
  3. 목표 본을 끌어 봅니다.팔다리가 목표를 따라 굽혀집니다.
  4. 5단계에서는 목표 본을 움직여 키를 찍어 애니메이션합니다.
항목의미
타깃따라갈 목표 본. 팔다리 안에 있으면 안 됩니다.
혼합0은 애니메이션 포즈 그대로, 1은 완전히 목표를 따라갑니다. 5단계에서 키를 찍어 "이 구간만 IK 끄기"를 만듭니다.
부드러움(2본) 다 뻗기 직전에 부드럽게 감속하는 거리.
굽힘 방향(2본) 무릎·팔꿈치가 접히는 쪽. 관절 옆 핸들을 끌거나 I를 누릅니다.
압축 / 늘이기목표가 가까우면 본을 줄이고(1본), 멀면 늘입니다.

다른 본 따라하기

원본 / 따라하는 본따라갈 본과 따라 하는 본들.

  • 제약 실행 순서는 목록 아래 제약 순서에 나옵니다. 위에서 아래로 실행되고, 끌어서 순서를 바꿉니다.

  • IK와 따라하기 예제는 spineboy(IK 7개)와 celestial-circus에 있습니다.

3-11머리카락과 천을 흔들리게 하려면: 물리

본이 애니메이션 포즈를 한 박자 늦게, 스프링처럼 따라가며 흔들립니다. 머리카락, 천, 꼬리, 가슴, 액세서리에 씁니다.

물리 만들기

  1. 1 뼈대에서 본을 고르고 흔들림 (물리) 그룹의 흔들림 (물리) 추가를 누릅니다.대화상자에서 이름을 확인하고 생성합니다. 처음에는 회전만 영향받고 감쇠 0.9라서 적당히 흔들리다 멈춥니다.
  2. 머리카락 가닥처럼 자식이 하나씩 이어진 체인이면 본마다 하나씩 만들기를 켭니다. 체인 전체가 한 번에 만들어집니다.
  3. 뷰포트 위쪽에 일시정지, 리셋, 끄기, 물리 미리보기 버튼이 생깁니다. 1~4단계에서는 물리 미리보기를 켜야 본을 끌 때 물리가 반응합니다.
항목의미

문제 해결

이미지가 안 보이고 "이미지가 없습니다"가 떠요

그림 경로는 문서 파일 기준 상대 경로입니다. 문서만 다른 폴더로 옮기면 어긋납니다. 그림 파일을 같이 옮기거나, 2 이미지에서 이미지 카드의 더 보기 > 이미지 파일 교체...로 다시 지정하세요. 새 문서는 그림을 불러온 뒤 그림 근처에 저장하는 것이 안전합니다.

파일이 어디에 저장되나요

다른 이름으로 저장...에서 고른 곳입니다. 제목 없음 상태에서 Ctrl+S를 누르면 위치를 묻습니다. GIF는 저장할 파일 칸의 경로입니다. 언어, UI 크기 같은 에디터 설정은 사용자 설정 폴더에 따로 저장됩니다.

예제에서 내보냈더니 examples 폴더에 파일이 생겼어요

기본 저장 위치가 문서 폴더이기 때문입니다. 찾아보기…로 다른 폴더를 고르세요.

4단계에서 "먼저 메쉬로 만드세요"가 나와요

다른 이미지를 골랐거나 아직 그림 상태입니다. 3단계로 이동해 메쉬 만들기를 누르세요.

팔을 돌렸더니 옆 다리나 몸이 같이 따라와요

그 메쉬에 해당 본이 없거나 가중치가 퍼져 있습니다. 다리와 몸에도 본을 두고, 4단계에서 자동으로 가중치 넣기를 다시 한 뒤 브러시로 문제 부위에서 그 본을 뺍니다 (Ctrl+드래그).

"키를 찍지 않은 변경 N개를 버렸습니다"가 떠요

자동 키가 꺼져 있었습니다. 값을 바꾼 뒤 K나 키 버튼으로 키를 찍고 나서 시간 막대를 옮기세요. 자동 키를 켜 두면 생기지 않습니다.

버튼이 흐려서 눌리지 않아요

조건이 안 맞으면 흐리게 보이고 바로 아래에 이유가 적힙니다. 예를 들어 가중치 편집은 5단계에서 안 되므로 1~4단계로 돌아가야 합니다.

root를 지울 수 없어요 / 본을 옮겼더니 그림이 안 따라와요

root는 지우거나 이름을 바꿀 수 없습니다. 본을 옮겨도 이미지가 그대로인 것은 셋업 포즈에서 메쉬가 본을 따라가지 않는 기본 설정 때문입니다 (3-4 참고). Alt+드래그는 일부러 이미지를 남깁니다.

시간 막대를 움직이면 물리 본이 튀어요

물리는 시간 순서대로 계산됩니다. 건너뛰었다면 리셋 (Shift+R)을 누르세요. 컷 전환에는 5단계에서 리셋 키를 찍습니다.

GIF 가장자리가 지저분해요 (흰 테두리)

투명 배경 GIF는 부드러운 가장자리가 배경색과 섞입니다. 배경을 올릴 페이지 색에 맞추거나 알파 임계값을 올리세요. 반투명이 필요하면 스프라이트 시트(PNG)를 쓰세요.

GIF가 너무 커요

픽셀 크기에 맞추기로 줄이고, FPS를 20~25로 낮추고, 색 수를 줄이고, 디더링을 끄고, 월드 영역으로 자르기로 여백을 줄여 보세요.

PSD를 가져왔는데 부품이 안 나뉘어요 / 숨긴 부분이 없어요

PSD 가져오기 창의 나누는 방법을 바꿔 보세요 (레이어마다가 가장 잘게 나뉩니다). 숨긴 레이어는 기본으로 가져오지 않으니 투명하게 가져오기나 보이게 가져오기를 고르세요.

저장하지 않았는데 "디스크의 파일이 변경되었습니다" 창이 떠요

명령줄이나 AI가 같은 파일을 고쳤습니다. 다시 불러오기 (내 변경 버리기) 또는 내 변경 유지 중에서 고르세요. 에디터는 자동 저장하지 않으니 Ctrl+S를 자주 누르세요.

A명령줄과 AI 연동

에디터와 같은 규칙으로 움직이는 skel2d.exe가 있습니다. 모든 명령은 JSON 한 줄을 출력합니다. 에디터를 켜 둔 채 같은 파일을 명령줄이나 AI가 고치면 에디터가 자동으로 다시 불러옵니다.

명령하는 일
skel2d info FILE본, 슬롯, 애니메이션 목록.
skel2d validate FILE문제가 있는지 검사.
skel2d render FILE -o out.png --anim A --frames 8PNG로 렌더링 (프레임 스트립).
skel2d gif FILE -o out.gif ...GIF 내보내기.
skel2d sheet FILE -o out.png --columns N --padding PX스프라이트 시트와 JSON.
skel2d apply FILE --ops '[...]'편집 연산을 한꺼번에 적용 (하나라도 실패하면 전부 취소).
skel2d psd 파일.psd -o partsPSD를 부위별 PNG로 분리.
skel2d rig img.png --spec spec.json -o out.skel.json그림 한 장과 관절 좌표로 본, 메쉬, 가중치를 자동 생성.
skel2d serve FILE --port 7878내 컴퓨터 전용 HTTP 서버.
skel2d mcp FILEAI 에이전트(MCP)용 서버.
claude mcp add skel2d -- skel2d mcp path\to\hero.skel.json

MCP를 지원하는 AI(예: Claude Code)에 이 한 줄로 연결하면 AI가 같은 문서를 읽고 고칩니다. 에디터에서 같은 파일을 열어 두면 수정이 화면에 바로 나타납니다.

전체 명령과 연산 목록은 AI_GUIDE.md에docs\AI_GUIDE.md에 모든 명령, 편집 연산, API가 정리되어 있습니다. PowerShell에서는 연산을 ops.json 파일에 쓰고 skel2d apply hero.skel.json ops.json으로 적용하는 것이 편합니다.

에디터 시작 옵션: skel2d-editor.exe 파일 [--anim 이름] [--time 초] [--step 1-5] [--select 본] [--select-slot 슬롯] [--tool 이름] [--lang ko|en] [--dialog 이름] [--screenshot 출력.png]. 이 설명서의 화면 그림도 이 옵션으로 찍었고, 스크린샷은 문서를 저장하지 않습니다.
