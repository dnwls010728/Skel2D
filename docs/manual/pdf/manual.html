1. 소개, 설치와 실행

1.1 Skel2D는 무엇인가요

Skel2D는 2D 그림을 뼈대(스켈레톤)로 움직이게 만드는 프로그램입니다. 캐릭터 그림 한 장 또는 부위별로 나눈 그림을 불러와 뼈를 심고, 뼈를 움직여서 걷기, 손 흔들기, 눈 깜빡임 같은 애니메이션을 만듭니다. 결과는 사람이 읽을 수 있는 JSON 파일(.skel.json)로 저장되고, 움직이는 GIF 이미지로도 내보낼 수 있습니다.

프로그램은 두 가지로 이루어져 있습니다.

  • skel2d-editor.exe: 마우스로 작업하는 데스크톱 에디터입니다. 이 설명서의 대부분은 에디터 이야기입니다.
  • skel2d.exe: 명령줄(CLI) 도구입니다. 파일 정보 확인, 그림 렌더링, GIF 내보내기, AI 에이전트 연동에 씁니다. 에디터만으로 작업할 수 있으니 처음에는 몰라도 됩니다 (10장에서 설명합니다).
이 설명서를 읽는 방법스켈레탈 애니메이션을 한 번도 해 본 적이 없어도 이 문서만으로 캐릭터 하나를 움직이게 만들 수 있습니다. 순서대로 읽으세요. 3장에서 용어를 먼저 익히고, 4장 튜토리얼에서 직접 따라 하면 됩니다. 화면에 보이는 글자는 파란 굵은 글씨로 적었고, 한국어 화면에 나오는 이름 그대로 씁니다.

1.2 설치와 실행

설치 프로그램은 없습니다. 압축 파일만 풀면 바로 실행됩니다.

내려받은 Skel2D-버전-win64.zip을 마우스 오른쪽 버튼으로 눌러 모두 압축 풀기를 고릅니다. 쓰기 가능한 폴더(예: 바탕화면, 문서, D:\Tools)에 푸세요. 압축을 풀지 않고 zip 안에서 바로 실행하면 예제 이미지를 찾지 못할 수 있습니다.Skel2D-버전-win64 폴더가 만들어집니다.
폴더 안의 skel2d-editor.exe를 더블클릭합니다.어두운 창이 뜨고, 위쪽에 1 뼈대 ~ 5 애니메이션 버튼 다섯 개가 보입니다. 가운데에 여기서 시작하세요 안내가 나옵니다.
안내 창의 예제 열기를 눌러 예제 하나를 열어 보세요. 또는 폴더의 examples 안 .skel.json 파일을 에디터 창에 끌어다 놓아도 됩니다.캐릭터 그림과 노란 뼈대가 화면에 나타납니다.

에디터를 닫을 때 저장하지 않은 변경이 있으면 종료하기 전에 변경 사항을 저장할까요? 창이 뜹니다. 저장 후 종료, 저장하지 않고 종료, 취소 중에서 고르세요.

1.4 Windows 보안 경고 (SmartScreen)

이 프로그램은 코드 서명(디지털 서명)이 되어 있지 않습니다. 그래서 처음 실행할 때 Windows가 "Windows의 PC 보호" 파란 창을 띄울 수 있습니다. 악성 프로그램이라는 뜻이 아니라 "이 프로그램을 널리 쓰는 사람이 아직 적다"는 뜻입니다.

창의 추가 정보를 누릅니다.
나타나는 실행 버튼을 누릅니다.에디터가 정상적으로 열립니다. 같은 파일은 다음부터 경고가 뜨지 않습니다.

zip 파일을 내려받았을 때 파일 속성에 차단 해제 체크 상자가 있으면 압축을 풀기 전에 체크해 두면 경고가 줄어듭니다. 출처가 확실한 파일만 실행하세요.

1.5 화면 언어 바꾸기

화면 위쪽 오른쪽의 언어 선택 상자(그림 2-1에서 "한국어"가 적힌 곳)에서 한국어와 English를 고릅니다. 바로 바뀌고, 다음 실행 때도 기억됩니다. 명령 검색(Ctrl+K)에서 "언어"를 검색해도 됩니다. 명령줄에서 skel2d-editor.exe 파일 --lang ko처럼 이번 실행만 언어를 정할 수도 있습니다.

글자가 작거나 크면 보기 메뉴의 UI 크기(100 / 125 / 150%) 또는 Ctrl+=, Ctrl+-로 조절합니다.

2. 화면 구성

에디터는 "지금 무엇을 하고 있는가"에 맞춰 화면이 바뀝니다. 위쪽의 번호 버튼 5개가 작업 순서입니다.

2.1 위쪽 줄

  • 메뉴: 파일(새로 만들기, 열기..., 저장, 다른 이름으로 저장..., 이미지 가져오기..., GIF 내보내기...), 편집(실행 취소, 다시 실행 등), 보기(본 표시, 전체 보기, 격자, UI 크기 등).
  • 명령 검색 Ctrl+K: 모든 동작, 본, 슬롯, 애니메이션을 이름으로 찾아 실행합니다 (아래 2.6).
  • 언어 선택 상자와 도움말(F1).
  • 단계 버튼: 1 뼈대, 2 이미지, 3 메쉬, 4 가중치, 5 애니메이션. 키보드 1~5로도 바꿉니다. 오른쪽 끝에는 실행 취소 Ctrl+Z와 다시 실행 Ctrl+Shift+Z 버튼이 있습니다.

2.2 왼쪽: 도구와 표시

왼쪽 도구 목록은 단계마다 달라집니다.

단계도구
1 뼈대선택(B), 새 본(N), 이동(V), 회전(C), 크기(X)
2 이미지, 5 애니메이션선택, 이동, 회전, 크기 (5단계에서는 값이 키로 기록됩니다)
3 메쉬메쉬(M) 도구 하나. 옵션은 오른쪽 패널에 있습니다.
4 가중치칠하기(G) 도구 하나.

그 아래 표시 영역에는 뼈대(본 보이기), 이름(본 이름 보이기), 스냅(회전·이동 격자 맞춤), 5단계에서는 어니언 스킨(앞뒤 프레임을 흐리게 겹쳐 보기) 체크 상자가 있습니다.

2.3 가운데: 뷰포트

그림과 뼈가 보이는 작업 영역입니다. 휠로 확대/축소, 가운데 또는 오른쪽 버튼 드래그로 화면 이동, F로 선택 항목 보기, Shift+F로 전체 보기입니다. 맨 위의 한 줄 안내는 지금 할 수 있는 일을 알려 주고, 단계에 따라 내용이 바뀝니다. 5단계에서는 뷰포트 둘레가 붉은 테두리로 바뀌고 왼쪽 위에 현재 애니메이션 이름과 시간이 표시되어 "지금은 키가 기록되는 중"임을 알려 줍니다.

2.4 오른쪽: 목록과 패널

위쪽은 단계의 목록입니다 (1단계 본 트리, 2단계 슬롯 목록, 3단계 메쉬 목록, 4단계 가중치를 넣을 메쉬 목록, 5단계 애니메이션 목록과 본 트리). 아래쪽은 고른 항목의 속성 패널입니다. 되지 않는 버튼은 흐리게 표시되고 바로 아래에 이유가 적힙니다.

2.5 아래쪽: 타임라인(5단계)과 상태 표시줄

5단계에서는 뷰포트 아래에 타임라인이 나타납니다 (5.5 참고). 맨 아래 상태 표시줄에는 단축키 힌트, 선택한 본/슬롯, 확대 비율이 나옵니다. 저장·편집 결과와 오류는 오른쪽 아래 알림에 한 번만 표시됩니다. 알림의 닫기 버튼(x)으로 바로 치울 수 있습니다.

2.6 명령 검색(Ctrl+K)과 도움말(F1)

Ctrl+K를 누르고 글자를 치면 일치하는 명령이 목록으로 나옵니다 (예: "GIF", "가중치", "새 스킨", 본 이름). Enter로 실행합니다. 메뉴나 패널 어디 있는지 모를 때 가장 빠릅니다. F1은 현재 단계의 도움말과 단축키 창을 엽니다.

2.7 저장과 실행 취소

거의 모든 편집은 Ctrl+Z로 되돌리고 Ctrl+Shift+Z(또는 Ctrl+Y)로 다시 합니다. Ctrl+S로 저장합니다. 파일이 외부 도구(명령줄, AI)로 바뀌면 에디터가 0.5초마다 확인해서 자동으로 다시 불러오고, 저장하지 않은 변경이 있으면 디스크의 파일이 변경되었습니다 창에서 다시 불러오기 (내 변경 버리기)와 내 변경 유지 중 고르게 합니다.

3. 핵심 개념

튜토리얼 전에 용어 아홉 개만 이해하면 됩니다. 사람의 몸에 빗대어 설명합니다.

본 (Bone, 뼈)

그림이 매달릴 뼈입니다. 막대 모양으로 보이고, 위치·회전·크기·길이를 가집니다. 본은 반드시 다른 본의 자식이 되어 트리를 이루며, 부모가 움직이면 자식도 따라 움직입니다 (어깨를 돌리면 팔꿈치와 손도 함께 돌아가듯이). 맨 위의 root는 모든 본의 뿌리이며 잠겨 있어 삭제·이름 변경·이동이 안 됩니다. 본은 눈에 보이는 물체가 아니라 "움직임의 기준점"입니다.

슬롯 (Slot)

본 위에 놓인 "그림 걸이"입니다. 슬롯 하나는 한 번에 그림 한 장만 보여 줍니다. 슬롯은 앞뒤 순서(그리기 순서)가 있어서 위에 있는 슬롯이 앞에 그려집니다. 이미지를 불러오면 파일마다 슬롯이 하나 생깁니다.

어태치먼트 (Attachment)

슬롯에 실제로 걸리는 그림입니다. 슬롯 하나에 어태치먼트를 여러 개 넣을 수 있습니다 (눈 뜬 그림, 감은 그림, 웃는 그림). 한국어 화면에서는 보통 "이미지" 또는 "이미지 카드"로 보입니다. 어태치먼트에는 두 종류가 있습니다.

  • 그림(리전): 직사각형 그림 한 장. 본과 함께 뻣뻣하게 움직입니다.
  • 메쉬: 삼각형으로 나뉜 그림. 여러 본에 걸쳐 구부러질 수 있습니다.

메쉬 (Mesh)

그림을 점(정점)과 삼각형으로 잘게 나눈 것입니다. 점이 움직이면 그림이 고무처럼 늘어나고 휘어집니다. 팔꿈치처럼 "구부러져야 하는" 부분에 필요합니다. 팔이나 다리를 부품별로 잘라 뼈에 하나씩 붙이면 메쉬가 필요 없습니다.

가중치 (Weight)

메쉬의 점 하나가 "어느 본을 얼마나 따라가는가"를 퍼센트로 정한 값입니다. 팔꿈치 안쪽의 점이 위팔 60%, 아래팔 40%이면 두 본의 중간쯤으로 움직입니다. 점마다 합계는 항상 100%입니다. 가중치가 없으면 메쉬 전체가 슬롯의 본만 따라갑니다.

셋업 포즈와 애니메이션 (키)

셋업 포즈는 아무 애니메이션도 재생하지 않을 때의 기본 자세, 곧 리그(뼈대 설계)입니다. 1~4단계는 이 기본 자세를 만듭니다. 애니메이션은 시간에 따른 변화의 모음이고, 키(키프레임)는 "이 시간에 이 값"을 기록한 점입니다. 키와 키 사이는 프로그램이 자동으로 채웁니다 (보간). 애니메이션의 값은 셋업 포즈에 대한 차이입니다. 회전 키 30°는 "셋업 자세에서 30° 더 돌린다"는 뜻이고 크기 키 1은 "그대로"입니다. 그래서 셋업 포즈를 나중에 고쳐도 애니메이션이 대체로 유지됩니다.

스킨 (Skin, 의상)

같은 뼈대와 같은 애니메이션을 두고 일부 슬롯의 그림만 바꿔 끼우는 묶음입니다. 기사 옷, 마법사 옷, 사냥꾼 옷처럼 입히는 옷 세트입니다. 한국어 화면에서는 의상 (스킨)이라고 부릅니다 (6장).

IK (Inverse Kinematics)

보통은 어깨를 돌려서 손이 움직이지만, IK는 반대로 손(목표)을 놓으면 팔이 알아서 굽혀지게 합니다. 발을 땅에 붙이고 몸만 움직이고 싶을 때 씁니다. 목표가 되는 본을 하나 두고 그 본을 움직입니다. 한국어 화면에서는 목표 따라가기 (IK)입니다 (7장).

물리 (Physics) 제약

본이 애니메이션 포즈를 한 박자 늦게, 스프링처럼 따라가며 흔들리게 합니다 (머리카락, 천, 꼬리). 화면에서는 흔들림 (물리)입니다. 키를 일일이 찍지 않아도 자연스러운 여운이 생깁니다 (7장).

한 줄 요약그림(어태치먼트)을 슬롯에 걸고, 슬롯을 본에 붙입니다. 메쉬로 바꾼 그림은 가중치로 여러 본에 나눠 묶습니다. 이렇게 만든 셋업 포즈 위에서 키를 찍어 애니메이션을 만듭니다.

4. 튜토리얼 A: 처음부터 캐릭터 만들기

제공된 소년 캐릭터 그림 한 장(examples\rig\character.png)으로 뼈대를 심고, 메쉬와 가중치를 넣고, 손을 흔드는 애니메이션 wave를 만듭니다. 한 시간이면 충분합니다. 이 튜토리얼의 화면 그림은 같은 작업을 마친 단계별 파일을 에디터로 열어 찍은 것이라 직접 하시면 본 위치만 조금 다릅니다.

완성된 모습을 먼저 보고 싶다면튜토리얼 시작 전에 examples\rig\character.skel.json을 열어 5 애니메이션에서 wave를 눌러 보세요. 이 파일은 더 많은 본과 IK를 쓰지만 목표 방향은 같습니다.

준비

탐색기에서 작업 폴더를 하나 만듭니다 (예: 문서\내캐릭터). examples\rig\character.png를 이 폴더로 복사합니다.작업 폴더에 character.png가 있습니다 (1086 x 1448 픽셀 그림).
에디터를 실행하고 파일 > 새로 만들기를 누릅니다 (이미 문서가 열려 있으면 저장 여부를 묻습니다).그림 1-1처럼 여기서 시작하세요 안내가 나오고, 오른쪽 목록에 root 본 하나만 있습니다.
파일 > 다른 이름으로 저장...으로 작업 폴더에 hero.skel.json이라는 이름으로 저장합니다.상태 표시줄에 "hero.skel.json 저장했습니다"가 뜹니다.
왜 먼저 저장하나요그림 경로는 문서 파일 기준 상대 경로로 저장됩니다. 문서와 그림이 같은 폴더에 있으면 파일을 통째로 옮겨도 그림을 잃지 않습니다.

단계 순서 안내

이 튜토리얼은 이미지를 먼저 불러오고(2단계) 그 위에 뼈를 그립니다(1단계). 뼈를 그릴 때 그림이 보여야 관절 위치를 정확히 맞출 수 있기 때문입니다.

단계 A-1. 이미지 불러오기 (2단계)

키보드 2 또는 2 이미지 버튼을 누릅니다.오른쪽 위에 파란 이미지 불러오기 버튼이 나타납니다.
이미지 불러오기를 누르고 작업 폴더의 character.png를 고릅니다. (또는 탐색기에서 파일을 뷰포트로 끌어다 놓습니다.)소년 그림이 뷰포트에 나타나고, 오른쪽 목록에 슬롯 character가 생기며 본은 root로 표시됩니다. 오른쪽 아래 알림에 "character.png를 본 root에 추가했습니다" 같은 메시지가 뜹니다.
목록의 character를 클릭합니다.그림에 파란 테두리가 생기고, 오른쪽 아래 패널에 이 슬롯의 이미지 (1)가 나옵니다. 카드 하나에 표시 중 글자와 그림(종류)이 보입니다.
Shift+F를 눌러 전체가 보이게 맞춥니다. 휠로 크기를 조절해도 됩니다.그림 전체가 뷰포트 가운데에 들어옵니다.
Ctrl+S로 저장합니다.
그림이 원점에서 어긋나 보여도 괜찮습니다이미지는 원점(0,0) 근처에 1픽셀 = 1단위로 놓입니다. 그림이 아래로 걸쳐 있어도 이후 본을 그림 위에 그리므로 문제없습니다.

단계 A-2. 뼈대 그리기 (1단계)

관절이 꺾이는 곳에 본을 심습니다. 몸통에서 바깥쪽으로 그립니다 (척추, 그다음 팔다리). 이번에는 본 11개를 만듭니다: hip, chest, head, arm_l, forearm_l, arm_r, forearm_r, thigh_l, shin_l, thigh_r, shin_r. (_l은 캐릭터의 왼쪽이며 화면의 오른쪽에 있습니다.)

1을 눌러 1 뼈대로 갑니다. 왼쪽 도구에서 새 본(N)을 고릅니다.뷰포트 맨 위 안내가 "뷰포트에서 끌어 본을 그립니다. 선택한 본(없으면 root)의 자식이 됩니다."로 바뀝니다.
허리(골반) 위치에서 가슴 높이까지 위로 끌어서 본을 그립니다 (마우스를 누른 채 이동하고 놓기).노란 막대 모양 본이 생기고 오른쪽 트리의 root 아래에 새 본이 나타납니다. 새 본이 선택된 상태입니다.
오른쪽 아래 속성 패널 맨 위의 이름 칸에서 본 이름을 hip으로 바꾸고 Enter를 누릅니다.트리의 이름이 hip으로 바뀝니다.
hip의 끝점(가슴 높이)에서 시작해 목 아랫부분까지 위로 끌어 두 번째 본을 그리고 이름을 chest로 바꿉니다. 끝점에서 이어서 그으면 부모-자식 체인이 됩니다.트리에서 chest가 hip 아래에 들여쓰기되어 있습니다.
chest의 끝(목)에서 머리 꼭대기까지 끌어 head 본을 만듭니다.
팔을 그립니다. 선택한 본이 부모가 되므로, 먼저 선택(B) 도구로 chest를 클릭해 선택하고 새 본(N)으로 돌아와 화면의 오른쪽(캐릭터의 왼쪽) 어깨에서 팔꿈치까지 끌어 arm_l을 만듭니다. 이어서 팔꿈치에서 손끝까지 끌어 forearm_l을 만듭니다.트리에서 arm_l은 chest 아래, forearm_l은 arm_l 아래에 있습니다.
같은 방식으로 반대쪽 팔 arm_r, forearm_r을 만듭니다 (chest를 다시 선택하고 시작).
다리를 그립니다. hip을 선택하고 골반 옆에서 무릎까지 thigh_l, 무릎에서 발목 근처까지 shin_l을 그립니다. 반대쪽도 thigh_r, shin_r.그림 4-2처럼 그림 위에 노란 본이 사람 모양으로 놓입니다.
Ctrl+S로 저장합니다.
잘못 그렸다면Ctrl+Z로 되돌리거나, 선택(B)으로 본을 골라 끌어서 옮기세요 (본을 끌면 이동, 끝 근처를 끌면 회전). 오른쪽 패널의 위치, 회전 숫자를 직접 고쳐도 됩니다. 숫자는 드래그로 바꾸고 더블클릭하면 직접 입력합니다.

단계 A-3. 메쉬 만들기 (3단계)

지금 그림은 직사각형 그림(리전)이라서 뼈가 움직여도 그림은 통째로 root만 따라갑니다. 팔다리가 따로 움직이도록 메쉬로 바꿉니다.

3을 눌러 3 메쉬로 갑니다. 오른쪽 목록에서 character를 클릭합니다.패널에 "아직 메쉬가 아닙니다. 메쉬로 바꾸면 이미지를 구부릴 수 있습니다."와 메쉬 만들기 버튼이 보입니다.
메쉬 만들기를 누릅니다.그림 4-3의 대화상자가 열리고 뷰포트에 미리보기 메쉬가 나타납니다. 아래쪽에 "정점 370개 · 삼각형 506개" 같은 수가 표시됩니다.
그대로 두거나 밀도를 보통으로 둡니다 (적게 / 보통 / 많게). 방식은 이미지 윤곽 따라가기가 기본이며 대부분의 부위에 알맞습니다. 값을 바꾸면 뷰포트에 즉시 반영됩니다. 파란 적용 버튼 또는 Enter로 확정합니다 (Esc/취소는 원래대로).그림 위에 청록색 외곽선과 점이 생기고, 패널에 "정점 N개, 삼각형 N개인 메쉬입니다."가 나옵니다. 목록의 character 옆 글자가 그림에서 메쉬로 바뀝니다.
필요하면 마우스 동작 이동(정점 끌기), 추가(클릭으로 정점 추가), 삭제, 접히는 선으로 다듬습니다. 팔꿈치와 어깨처럼 구부러지는 곳에 점이 많으면 부드럽게 휩니다. 이번 튜토리얼은 그대로 써도 됩니다.
본을 먼저 그려야 하는 이유메쉬 점은 본의 관절 주변에 촘촘하게 생기는 경향이 있습니다. 뼈를 먼저 그리면 구부러질 곳에 점이 모입니다. 그래서 이 튜토리얼은 뼈대(A-2)를 3단계 앞에 했습니다.

단계 A-4. 가중치 넣기 (4단계)

4를 눌러 4 가중치로 갑니다. 목록에서 character를 고릅니다."가중치 없음: 이미지 전체가 본 root를 따라갑니다." 같은 한 줄 상태와 파란 자동으로 가중치 넣기 버튼이 보입니다.
자동으로 가중치 넣기를 누릅니다. (정점당 본 수는 4가 기본입니다.)"본 11개에 묶여 있습니다." 로 바뀌고, 뷰포트의 점들이 파란색(0%)~붉은색(100%) 히트맵으로 칠해집니다 (그림 4-5).
아래 묶인 본 (클릭하면 그 본을 칠합니다) 목록에서 forearm_l 같은 본을 눌러 보세요.그 본이 영향을 주는 부분이 붉게, 영향이 없는 곳은 파랗게 나타납니다.
결과 확인 아래 본을 돌려 확인하기를 체크하고 뷰포트에서 팔 본을 끌어 돌려 봅니다. 또는 체크 없이 Alt를 누른 채 본을 끌어도 됩니다.그림이 본을 따라 구부러집니다. 놓으면 원래대로 돌아오고 문서는 바뀌지 않습니다.
어색한 곳(예: 어깨 주변이 꺾이거나 한 다리가 다른 본에 끌려오는 곳)이 있으면 문제가 되는 본을 목록에서 고르고 브러시로 칠합니다. 모드는 추가 / 빼기 / 지정, Ctrl+드래그는 지우기, [ ]는 브러시 크기입니다.
Ctrl+S로 저장합니다.
참고이 그림에서 대부분의 점이 파랗게 보이는 이유는 "선택한 본(arm_l)의 영향" 히트맵이기 때문입니다. 팔 쪽 점만 붉거나 따뜻한 색이 됩니다.

단계 A-5. 손 흔들기 애니메이션 (5단계)

목표: 1초짜리 반복 애니메이션 wave. 시간 0에서 팔을 내린 자세, 0.5초에서 팔을 위로 올리고, 1초에서 다시 내린 자세로 돌아옵니다. 팔꿈치는 흔들고, 머리는 살짝 기웁니다.

5를 눌러 5 애니메이션으로 갑니다. 오른쪽 위의 새 애니메이션 버튼을 누릅니다.새 애니메이션 대화상자가 열립니다.
이름을 wave, 길이(초)를 1로 두고 생성을 누릅니다 (Enter도 됩니다).뷰포트 둘레가 붉은 테두리로 바뀌고 왼쪽 위에 wave · 0.00s f0와 자동 키: 켜짐이 나옵니다. 아래에 타임라인이 나타납니다.
트리에서 arm_l을 선택합니다. 시간이 0인 상태에서 오른쪽 패널의 애니메이션 그룹 안 회전 옆 키 버튼(빈 마름모, 키)을 누릅니다. 또는 K.키 버튼이 빨간 채운 마름모(키 있음)로 바뀌고, 타임라인의 arm_l 행 0초에 마름모가 생깁니다.
시간 막대를 0.5초로 옮깁니다. 타임라인 눈금을 클릭/드래그하거나, 위쪽 시간 칸에 0.5를 입력합니다.시간 막대가 0.5s f15에 놓이고, 뷰포트 왼쪽 위가 wave · 0.50s f15가 됩니다.
왼쪽 도구에서 회전(C)을 고르고 arm_l을 끌어 팔을 위로 올립니다 (또는 패널의 회전 칸에 110 입력). 자동 키가 켜져 있으므로 바로 키가 기록됩니다.팔이 위로 올라가고 arm_l 행 0.5초에 마름모가 생깁니다.
시간을 1.0초로 옮기고 arm_l의 회전 값을 0으로 입력(또는 회전 0°로 키 기록 사용)합니다.arm_l 행에 0, 0.5, 1.0초의 키 3개가 있습니다.
Space로 재생해 봅니다. 아래 반복 체크가 켜져 있으면 계속 돌아갑니다. 다시 Space로 멈춥니다.팔이 올라갔다 내려옵니다. 어깨 주변 옷이 조금 구겨져 보이면 4단계에서 가중치를 다듬으세요.
같은 방법으로 forearm_l에 손 흔들기를 넣습니다: 0초 회전 0, 0.25초 25, 0.5초 -25, 0.75초 25, 1초 0. head에는 0초 0, 0.5초 -8, 1초 0.forearm_l 행에 키 5개, head 행에 키 3개가 보입니다.
키 사이를 부드럽게 하려면 타임라인에서 키를 고르고 보간(Curve)에서 천천히 시작/끝을 고릅니다. 오른쪽 그래프에서 곡선이 부드러워진 것을 볼 수 있습니다.
Ctrl+S로 저장합니다.

5. 단계별 상세 참조

5.1 뼈대 (1단계)

본 목록(트리)

  • 맨 위 root는 잠겨 있습니다. 모든 본이 root 아래에 달리며, 삭제·이름 변경·이동을 누르면 이유가 표시됩니다.
  • 본을 다른 본 위로 끌어다 놓으면 부모가 바뀝니다 (위치는 유지됩니다). 부모 없이 둘 수는 없습니다.

  • 제약(IK/물리/따라하기)이 있으면 목록 아래 제약 순서에 평가 순서대로 나옵니다. 위에서 아래로 실행되며 끌어서 순서를 바꿉니다.

5.2 이미지 (2단계, PSD 포함)

이미지 불러오기

  • 방법 세 가지: 오른쪽 위 이미지 불러오기 버튼, 파일 > 이미지 가져오기..., 또는 파일을 뷰포트에 끌어다 놓기.
  • PNG 파일마다 슬롯이 하나 생기고, 그림은 1픽셀 = 1단위, 세워진 채로 놓입니다. 끌어다 놓으면 놓은 위치 중심에, 놓은 위치의 본(없으면 선택한 본, 그도 없으면 root)에 붙습니다.
  • 슬롯이 이미 선택되어 있는 상태에서 불러오면 이미지를 어디에 넣을까요? 창이 떠서 슬롯 ○○에 추가(다른 모습으로)와 새 슬롯 중에서 고르게 합니다.
  • 목록은 앞뒤 순서(위가 앞)입니다. 끌어서 순서를 바꿉니다. 썸네일, 번호, 소속 본이 보입니다.

슬롯 패널

  • 이 슬롯의 이미지 (N): 카드 목록. 카드에는 썸네일, 이름, 종류(그림 / 메쉬 / 공유 메쉬), 표시 중 표시가 있습니다. 카드를 누르면 아래에 그 이미지의 위치/회전/크기 값이 나옵니다. 표시는 슬롯이 보여 줄 이미지로 지정, 더 보기는 이름 변경, 이미지 파일 교체..., 메쉬로 변환 (3단계), 이미지 삭제입니다.
  • 이미지 추가: PNG를 여러 장 골라 이 슬롯에 다른 모습으로 더합니다 (눈 뜬/감은 모양, 입 모양). 같은 이름이면 _2가 붙고, 전체가 undo 한 번으로 되돌려집니다.
  • 슬롯 설정: 소속 본(바꿔도 그림은 화면에서 제자리), 색(곱해지는 색조와 알파), 블렌드(더하기 (빛), 곱하기 (그림자), 스크린 (부드러운 빛)), 앞뒤 순서.
  • 어태치먼트 이름은 카드의 더 보기 > 이름 변경 또는 F2로 바꿉니다.

PSD(포토샵) 파일

레이어가 나뉜 PSD를 불러오면 부위별 PNG로 자동 분리합니다. PSD를 고르면 PSD 가져오기 대화상자가 열립니다.

  • 최상위 그룹마다(기본 선택): 그룹(폴더) 하나가 부위 하나가 됩니다. 그룹 안 레이어는 이미지 하나로 합쳐집니다 (예: 선화 + 채색). 그룹 밖의 레이어 한 장은 그 자체가 부위입니다.
  • 레이어마다: 레이어 하나가 부위 하나입니다. 그룹은 정리용일 뿐입니다 (레이어마다 한 부품인 PSD에 알맞습니다).
  • 가져오기(Enter)로 실행하고 취소(Esc)로 닫습니다.
  • 결과: PSD 옆에 새 <이름>_parts 폴더가 생기고 부위별 PNG가 저장되며, 각 PNG가 슬롯이 됩니다. 원래 위치가 유지되므로 캐릭터가 PSD 그대로 조립됩니다. 숨겨진 레이어도 포함되고 종이 배경 레이어(용지/Paper)는 건너뜁니다. 오른쪽 아래 알림에 "PSD 파츠를 ○○에 저장했습니다"가 뜹니다.
문서를 저장하세요PSD 가져오기 직후 문서를 저장하면 이미지 경로가 상대 경로로 저장됩니다. 명령줄 skel2d psd 파일.psd -o parts도 같은 일을 합니다 (10장).

5.4 가중치 (4단계)

메쉬를 고르면 한 줄 상태가 나옵니다: "가중치 없음: 이미지 전체가 본 ○○를 따라갑니다." 또는 "본 N개에 묶여 있습니다." 메쉬가 아니면 "먼저 메쉬로 만드세요"와 3단계로 이동해 메쉬 만들기 버튼이 나옵니다.

순서

  1. 자동으로 가중치 넣기를 먼저 누릅니다. 이미지를 지나는 본을 기준으로 가중치가 정해집니다. (정점을 골랐으면 자동으로 가중치 넣기 (정점 N개).) 정점당 본 수는 한 점을 움직일 수 있는 최대 본 수입니다. 대안: 거리 기준으로(이미지와 상관없이 각 본까지의 거리).
  2. 묶인 본 목록: 본마다 막대와 % 숫자, 잠금 버튼. 행을 누르면 그 본이 칠할 본이 되고 뷰포트에 히트맵(파랑 0% ~ 빨강 100%)이 나옵니다. + 본으로 영향도 0인 본을 묶고, 선택 본 제거는 가중치를 누구에게 넘길지(재분배: 자동 / 가장 가까운 본 / 부모) 고르는 미리보기 대화상자를 엽니다.
  3. 브러시: 추가(칠하는 본 가중치를 올림), 빼기, 지정(강도 값에 맞춤). 크기, 강도, 페더 슬라이더. 드래그로 칠하고 Ctrl+드래그는 지웁니다. 다른 본은 점마다 합이 100%가 되도록 자동 조정됩니다.
  4. 결과 확인: 본을 돌려 확인하기 또는 뷰포트에서 Alt+드래그(T를 누르는 동안 칠하면 테스트 포즈에서 칠함). 놓으면 원래대로 돌아오고 문서와 실행 취소 기록은 바뀌지 않습니다.

잠금

잠금을 켠 본의 가중치는 브러시, 붙여넣기, 스무스, 정리, 자동 가중치, 미러, 전송이 건드리지 않습니다. 잠금은 작업 중 설정이며 문서에는 저장되지 않습니다. 선택은 Shift+클릭, Ctrl+A(전체), Esc(해제)입니다. 가중치 편집은 5단계에서는 할 수 없습니다.

5.5 애니메이션 (5단계)

애니메이션 만들기와 고르기

오른쪽 위 새 애니메이션(또는 Ctrl+K의 새 애니메이션)이 만드는 대화상자에서 이름, 길이(초), FPS를 정하고 생성을 누릅니다. 현재 애니메이션을 현재 애니메이션 복제할 수도 있습니다. 목록의 이름을 클릭하면 편집이 시작되고, 다시 클릭하면 셋업 포즈로 돌아가며, 우클릭으로 이름 변경과 삭제를 합니다. 아직 하나도 없으면 안내가 나옵니다. 1~4단계에서 5단계로 돌아오면 마지막으로 편집하던 애니메이션이 다시 열립니다.

타임라인 읽는 법

  • 제어 줄: 애니메이션 선택 상자, 재생/일시정지(Space), 반복, 재생 속도 1x, 시간(초, 직접 입력 가능)과 프레임 번호 칸(숫자를 쓰고 Enter), 모든 행(켜면 모든 본의 행, 끄면 선택한 본 관련만), 길이.
  • 개요 행은 모든 키를 합친 요약입니다. 그 아래 본, 슬롯, IK, 물리, 그리기 순서, 이벤트 구역이 있고, 행 왼쪽 화살표로 속성별(회전/이동/크기, 색, 디폼 ...)로 펼칩니다.

  • 자동 키(기본 켜짐): 시간 막대를 옮기고 본을 움직이거나 값을 바꾸면 그 시간에 바로 키가 기록됩니다. 끄면 변경은 주황 원(변경됨) 상태로 남고 K나 키 버튼으로 찍어야 합니다. 찍지 않고 시간 막대를 옮기면 알림과 함께 버려집니다.
  • 키 버튼은 모양과 글자로 상태를 말합니다: 빨간 채운 마름모 키 있음(이 시간에 키가 있음), 빈 마름모 키(키 없음) 또는 점 있는 빈 마름모 사이(다른 시간에 키가 있어 값이 보간 중), 주황 채운 원 변경됨(바꿨지만 키 없음). 누르면 현재 값으로 키를 기록합니다.
  • K: 선택한 본에 키(바꾼 속성만, 없으면 현재 도구의 속성). 모든 보이는 행에 키는 Ctrl+Shift+L.
  • 키 편집: 키를 끌어 시간 이동(Alt: 스냅 해제, Ctrl+Shift: 복사), 더블클릭으로 삭제, 행을 클릭하면 아래 키 전체 선택, Ctrl+A 전체 선택, Del 삭제, 복사/붙여넣기 버튼.

보간 (커브)

키를 고르면 타임라인 오른쪽에 보간 그래프와 선택 상자가 나타납니다. 이 키에서 다음 키까지 값이 변하는 방식입니다: 선형(일정한 속도), 계단(다음 키에서 갑자기 바뀜), 천천히 시작, 천천히 끝, 천천히 시작/끝, 베지어(그래프의 두 점을 끌어 직접 모양을 만듦). 걷기 같은 반복 동작은 시작/끝을 부드럽게 하면 자연스럽습니다.

이미지 바꾸기 (눈 깜빡임, 입 모양)

슬롯을 고르면 패널에 그 슬롯의 이미지 카드가 나오고, 카드를 누르면 지금 시간부터 그 이미지로 바뀌는 키가 만들어집니다 (슬롯 숨기기 카드 포함). 눈 깜빡임: 눈 슬롯에 "뜬 눈"과 "감은 눈"을 넣고(2단계), 감을 시간에 감은 눈 카드, 바로 뒤에 뜬 눈 카드를 누릅니다. 슬롯의 색조(알파)도 키로 기록해 페이드 효과를 만들 수 있습니다.

그리기 순서 (Draw order)

슬롯의 앞뒤 순서도 시간에 따라 바꿀 수 있습니다 (예: 걷는 동안 팔이 몸 앞과 뒤를 오가기). 타임라인의 그리기 순서 구역에서 현재 시간 기준 순서를 보고, 슬롯 옆 위/아래 화살표로 한 칸씩 이동하면 이 시간에 키가 기록됩니다. 키는 현재 순서를 키로 기록, 셋업 순서는 2단계에서 정한 원래 순서로 되돌리는 키, 키 삭제는 이 시간의 키를 지웁니다. 키는 다음 키까지 유지됩니다.

이벤트 (Events)

이벤트는 발소리처럼 이름 붙은 순간입니다. 게임 쪽에 "지금 소리를 내라"고 알립니다. 타임라인의 이벤트 구역에서 이벤트 추가…로 이름과 기본값(정수, 소수, 문자열)을 정의하고, 이벤트를 고른 뒤 재생 헤드에 키로 현재 시간에 발생시킵니다. 키마다 값을 덮어쓸 수 있습니다. spineboy의 footstep이 예입니다.

함께 재생할 애니메이션 (레이어)

타임라인 위쪽 함께 재생할 애니메이션에서 애니메이션 추가로 다른 애니메이션을 더하면 작업 중인 애니메이션 위에 겹쳐 재생합니다 (미리보기 전용; 문서는 바뀌지 않음). 목록은 아래부터 적용되므로 위에 놓인 것이 나중에 덮어씁니다. 끌어서 순서를 바꾸고, 체크로 켜고 끄고, 불투명도를 조절하고, 제거합니다. 편집 중인 애니메이션은 트랙 0으로 맨 아래에 고정됩니다. 눈 깜빡임(blink)과 말하기(talk)를 걷기 위에 겹쳐 보는 식으로 씁니다. 겹쳐 둔 레이어는 GIF 내보내기에도 그대로 들어갑니다 (8장).

표정 포즈

시간 0에 키 하나만 찍은 애니메이션(예: face/happy)을 "얼굴 포즈"로 쓸 수 있습니다. 슬롯의 이미지 카드를 눌러 눈/입/눈썹을 정하고, 다른 애니메이션 위에 함께 재생으로 겹칩니다. 이미지 키에서 (아래 트랙 / 셋업)(리셋 키)을 고르면 아래 레이어가 보여 주는 것(예: 해당 표정의 눈)으로 돌아갑니다.

어니언 스킨

왼쪽 어니언 스킨(O)을 체크하면 앞뒤 프레임이 흐리게 겹쳐 보여 움직임의 궤적을 확인하기 좋습니다.

6. 스킨(의상) 튜토리얼

같은 뼈대와 애니메이션으로 옷만 바꾸는 방법입니다. examples\skins를 씁니다: 뼈대 하나, 의상 세 벌(knight, mage, ranger), 애니메이션 idle(2초), walk(0.8초), wave(1.5초).

6.1 플레이스홀더란

스킨은 슬롯의 이미지 자리에 이름표(플레이스홀더)를 두고, 의상마다 그 이름표에 해당하는 그림을 따로 갖는 방식으로 동작합니다. 예를 들어 슬롯 torso에는 "torso"라는 이름표만 있고, knight 의상은 "torso"에 갑옷 그림, mage 의상은 "torso"에 로브 그림을 지정합니다. 의상을 켜면 이름표가 해당 그림으로 바뀌어 보입니다. 이름표 이름은 모든 의상에서 같아야 합니다 (그래서 애니메이션의 이미지 키도 의상이 바뀌어도 그대로 작동합니다). 이 예제에서 슬롯 head의 얼굴은 모든 의상이 공유하는 기본(default) 그림이고, 나머지는 의상별입니다. 슬롯 패널에서 이 슬롯의 이미지 (0)처럼 기본 이미지가 0개인 슬롯은 의상이 채워 주는 자리입니다.

7. IK, 물리, 따라하기 제약

세 가지 제약은 모두 1단계에서 만들고, 오른쪽 트리에 있는 제약 순서 목록에 평가 순서대로 나타납니다. 위에서 아래로 실행되며 끌어서 순서를 바꿉니다 (제약 순서의 숫자가 작을수록 먼저).

7.1 목표 따라가기 (IK)

언제 쓰나요: 발이 땅에 붙어 있어야 하는 다리, 물건을 향해 뻗는 팔처럼 "끝이 가야 할 곳"이 정해진 경우입니다.

1단계에서 팔이나 다리의 끝 본(예: 정강이 shin_l)을 선택합니다.
본 패널의 목표 따라가기 (IK) 그룹에서 목표 따라가기 (IK) 추가를 누릅니다. (본 우클릭 메뉴의 IK 제약 추가, 또는 Ctrl+K의 새 제약도 됩니다.)선택한 본의 끝에 <본이름>_target 본과 IK 제약이 생깁니다. 선택한 본과 그 부모 두 개가 하나의 팔다리로 묶입니다. 트리의 제약 순서에 새 줄이 생깁니다.
목표 본을 끌어 봅니다.팔다리가 목표를 따라 굽혀집니다.
항목의미
타깃따라갈 목표 본. 팔다리 안에 있으면 안 됩니다.
혼합IK가 얼마나 적용되는지. 0은 애니메이션 포즈 그대로, 1은 완전히 목표 따라감. 5단계에서 키를 찍을 수 있어 "이 구간만 IK를 끄기" 같은 효과를 냅니다 (혼합 키 기록).
부드러움(2본) 다 뻗기 직전에 부드럽게 감속하는 거리.
굽힘 방향(2본) 무릎·팔꿈치가 접히는 쪽. 관절 옆의 동그란 핸들을 반대편으로 끌거나 I로 바꿉니다.
압축 / 늘이기목표가 너무 가까우면 본을 줄이거나(줄이기, 1본), 멀면 늘림(늘이기 켜기).

5단계에서는 목표 본을 움직여 키를 찍어 애니메이션합니다. examples\arm은 가장 단순한 예입니다 (두 본 팔이 goal 본을 따라가는 wave).

7.2 흔들림 (물리)

본이 애니메이션 포즈를 한 박자 늦게, 스프링처럼 따라가며 흔들립니다 (머리카락, 천, 꼬리, 가슴, 액세서리).

본을 선택하고 본 패널의 흔들림 (물리) 그룹에서 흔들림 (물리) 추가를 누릅니다. (우클릭 메뉴 물리 제약 추가, Ctrl+K 새 물리 제약도 가능합니다.)대화상자가 열립니다. 이름을 확인하고 생성을 누르면 회전만 영향을 받는 기본 제약이 만들어집니다 (감쇠 0.9라서 적당히 흔들리다 멈춥니다).
선택한 본 아래로 자식이 하나씩 이어진 체인(머리카락 가닥)이면 본마다 하나씩 만들기를 체크해 한 번에 체인 전체에 만듭니다 (undo 한 번).
뷰포트 위쪽에 일시정지 / 리셋 / 끄기 / 물리 미리보기 버튼이 생깁니다. 1~4단계에서는 물리 미리보기를 켜면 본을 끌거나 root를 움직일 때 물리가 반응합니다 (기본 꺼짐).
항목의미
영향시뮬레이션이 어느 속성을 움직일지: 위치 X/Y, 회전, 크기, 셰어. 0이면 그 속성은 흔들리지 않습니다.
프리셋머리카락/천/꼬리/가슴/액세서리 값 묶음을 한 번에 채웁니다. 이후 자유롭게 고칩니다.
관성본 자체 움직임에 얼마나 저항하는지. 1은 완전히 뒤처짐, 0은 본을 그대로 따름.
강도애니메이션 포즈로 되돌리는 스프링 강성.
감쇠1/60초마다 유지되는 속도. 1이면 속도를 잃지 않아 영원히 흔들립니다. 멈추도록 1보다 작게 두세요.
질량무거울수록 힘에 덜 반응합니다.
바람 / 중력월드 x축 방향 일정 가속, 중력은 양수면 아래로 처집니다.
혼합시뮬레이션이 얼마나 보일지. 0이면 애니메이션 포즈 유지.
스텝 / 속도 제한초당 시뮬레이션 횟수와 속도 제한 (고급).
공유 값 및 값 옆 GG를 켠 값은 공유 값 그룹의 전역 값을 읽습니다. 여러 제약을 한 번에 조절할 때 씁니다.
흔들어 보기선택 제약에 충격을 주어 설정을 확인합니다 (미리보기만, 문서는 안 바뀜).

5단계에서: 물리 값(동작, 환경, 혼합)은 셋업을 바꾸지 않고 시간 막대 위치에 키가 찍힙니다. 리셋 키는 그 시간에 시뮬레이션을 다시 시작합니다 (장면 전환처럼 순간이동할 때). 타임라인의 물리 구역에 속성별 행이 보입니다. 본·영향·프리셋 같은 리그 설정은 1~4단계에서만 바꿉니다. 정지 상태에서 시간 막대를 앞뒤로 끌어도 처음부터 재생한 결과와 같게 보입니다. 뷰포트에서 물리 본에는 작은 물결 표시가 붙고, 시뮬레이션이 포즈에서 벗어나 있으면 원래 위치가 흐린 고스트로 보입니다. GIF 내보내기에서는 물리 시뮬레이션(기본 켜짐)과 예열로 처음부터 흔들리는 상태를 담습니다.

7.3 다른 본 따라하기 (변환 제약)

8.1 기본 사용법

파일 메뉴에서 GIF 내보내기... (Ctrl+E)를 누릅니다 (또는 Ctrl+E, Ctrl+K에서 "GIF").GIF 내보내기 창이 열립니다 (그림 8-1). 편집 중인 애니메이션이 선택되어 있고 "40프레임, 0.80초" 같은 요약이 나옵니다.
저장할 파일의 찾아보기…를 눌러 저장 위치를 정하거나 칸에 직접 씁니다. 기본값은 문서 폴더의 문서이름-애니메이션이름.gif입니다.
필요하면 아래 설정을 바꿉니다. 처음에는 그대로 두어도 충분합니다.
내보내기를 누릅니다.오른쪽 위에 GIF 내보내는 중 창이 뜹니다. 파일 이름, 진행률, 여러 파일일 때 현재 파일 번호가 표시됩니다. 취소를 누르면 취소 중...으로 바뀌고 버튼이 비활성화됩니다. 완료·실패·취소 결과는 오른쪽 아래 알림으로 나옵니다. 내보내기는 백그라운드에서 돌아가므로 그동안 편집을 계속해도 됩니다 (문서 복사본으로 만듭니다).

Ctrl+Shift+E는 창을 열지 않고 마지막 설정 그대로 다시 내보냅니다 (명령 검색에도 있습니다). 아직 내보낸 적이 없으면 "아직 내보낸 적이 없습니다. Ctrl+E로 내보내기 창을 여세요."가 나옵니다. 설정은 다음 실행에도 기억됩니다.

8.2 설정 항목

내보낼 대상 / 스킨 / 저장 위치

  • 내보낼 대상: 애니메이션 하나, 셋업 포즈(정지 이미지, 파일 1개), 모든 애니메이션 (각각 한 파일).
  • 스킨(문서에 스킨이 있을 때만 보임): 미리 보는 스킨(현재 눈 버튼으로 켠 스킨) / 스킨마다 한 파일.
  • 모든 애니메이션 또는 스킨마다를 고르면 저장할 폴더를 정하고, 파일 이름은 애니메이션-스킨.gif 규칙으로 자동으로 붙습니다. 둘 다 고르면 애니메이션 x 스킨 조합 전부가 만들어집니다. 기본 폴더는 문서 옆 gif입니다.
  • 함께 재생할 애니메이션(5.5)과 미리 보는 스킨은 그대로 GIF에 들어갑니다. 표정 레이어를 겹쳐 두고 내보내면 눈 깜빡임이 포함됩니다.

시간

항목설명
FPS초당 프레임 수. 최대 50이며 기본 50입니다.
무한 반복켜면 끝없이 반복(기본), 끄면 한 번 재생.
마지막 프레임 포함반복 애니메이션은 꺼 두세요. 마지막 프레임이 첫 프레임과 같아 이어붙일 때 한 프레임 멈칫합니다. 한 번만 재생하는 애니메이션이면 켜세요.
재생 횟수파일 안에 애니메이션을 담을 횟수 (기본 1).
끝난 뒤 멈춤 (초)재생이 끝날 때마다 마지막 프레임을 유지합니다. 손 흔들기 사이에 쉬는 시간처럼.
예열 (재생 횟수)먼저 이만큼 시뮬레이션해 물리가 이미 흔들리는 상태로 시작합니다. 머리카락이 가만히 있다가 움직이는 첫 순간을 없앱니다.
일부 프레임만첫 프레임~마지막 프레임 범위만 저장 (0부터 센 프레임 번호).
왜 FPS는 최대 50인가요GIF는 프레임 길이를 100분의 1초 단위로 저장합니다. 50fps는 프레임당 2/100초이고, 그보다 빠르게(1/100초) 지정하면 대부분의 뷰어가 느리게 재생해 버립니다. 그래서 50이 GIF가 낼 수 있는 가장 부드러운 속도입니다. 용량이 중요하면 20~25로 낮추세요. 연속 프레임이 완전히 같으면 하나로 합쳐 저장되어 프레임 수가 예상보다 적게 나올 수 있습니다 (움직임이 없는 구간).

크기

  • 배율 (%): 월드 단위 기준 확대/축소. 기본 100 (1단위 = 1픽셀).
  • 픽셀 크기에 맞추기: 너비 x 높이 안에 내용이 들어가게 맞춥니다 (최대 4096). 켜면 배율은 무시됩니다. 하위 옵션: 작은 내용 확대(작은 내용도 한계에 닿을 때까지 키움), 정확한 크기로 (주변 여백 추가)(항상 정확히 그 크기, 내용 주변은 여백).
  • 월드 영역으로 자르기: 월드 좌표의 사각형(x, y, 너비, 높이)만 담습니다. 내용 크기가 프레임마다 달라 이미지가 흔들릴 때, 고정된 영역으로 자르면 흔들리지 않습니다.

색

  • 색 수: 팔레트 크기 (2~256). 적을수록 파일이 작아집니다.
  • 디더링: 그라데이션이 부드러워지지만 파일이 커집니다.
  • 품질 (1~10): 높을수록 색이 좋아지고 오래 걸립니다.
  • 배경: 배경색 (기본 흰색).
  • 투명 배경 + 알파 임계값(0~255, 기본 128): 배경을 투명하게 합니다. 임계값보다 흐린 픽셀은 투명해집니다.
GIF의 투명은 "있다/없다"뿐입니다GIF 픽셀은 불투명이거나 완전히 투명이어서 반투명을 표현하지 못합니다. 그래서 그림의 부드러운 가장자리(안티앨리어싱)는 배경색과 섞인 채 불투명하게 저장됩니다. 투명 배경을 쓸 때는 배경 색을 GIF를 올려 둘 페이지 색과 비슷하게 고르세요. 그렇지 않으면 흰 배경 위에서는 문제없던 그림이 어두운 페이지 위에서 가장자리에 흰 테두리(헤일로)가 보입니다. 아래 그림은 같은 투명 GIF를 밝은 배경과 어두운 배경 위에 놓은 모습입니다. 어두운 쪽 가장자리를 보세요.

표시

  • 본 그리기: 본을 GIF에 그립니다 (기본 꺼짐).
  • 물리 시뮬레이션: 켜면 물리 제약을 시뮬레이션합니다 (기본 켜짐). 끄면 순수한 애니메이션 포즈만.

8.3 실제 내보낸 결과 예

아래 프레임들은 skel2d gif로 실제로 내보낸 GIF에서 꺼낸 것입니다.

8.4 명령줄로 내보내기

skel2d gif FILE -o OUT.gif --anim walk --gif-fps 25 --fit 400x400
skel2d gif FILE -o OUT.gif --anim wave --skin mage --transparent --background 202020
skel2d gif FILE -o 폴더 --all-animations --skin ranger     # 애니메이션마다 한 파일
skel2d gif FILE -o 폴더 --all-skins --anim idle             # 스킨마다 한 파일
skel2d gif FILE -o OUT.gif --anim blink --track face/happy  # 다른 애니메이션을 겹쳐서
skel2d gif FILE -o OUT.gif                                  # --anim 없이: 셋업 포즈
옵션에디터 항목
--anim, --track(반복), --skin(반복)내보낼 대상, 함께 재생, 스킨
--all-animations, --all-skins, -o 폴더모든 애니메이션 / 스킨마다 한 파일
--gif-fps (최대 50, 기본 50)FPS
--no-loop, --include-last-frame, --plays, --pause-after, --warm-up, --range 첫-끝시간 그룹
--scale(%), --fit WxH, --enlarge, --pad, --crop X,Y,W,H크기 그룹
--colors, --dither, --quality, --background RRGGBB, --transparent, --alpha-threshold색 그룹
--bones, --no-physics표시 그룹

결과는 JSON 한 줄로 나옵니다 ({"files":[{"out":..., "bytes":..., "stats":{"width":..,"height":..,"frames":..,"seconds":..,"colors":..,"missing_images":[]}}]}). missing_images에 이름이 나오면 그림 파일을 찾지 못한 것입니다.

10. 명령줄과 AI 연동

에디터와 같은 규칙으로 움직이는 명령줄 도구 skel2d.exe가 있습니다. 모든 명령은 JSON 한 줄을 출력하고 오류는 stderr에 JSON으로 나오며 종료 코드 1입니다. 에디터를 켜 둔 채 같은 파일을 명령줄이나 AI가 고치면 에디터가 0.5초 안에 자동으로 다시 불러옵니다. 아래 명령은 모두 이 설명서를 쓰면서 직접 실행해 확인했습니다. (PowerShell이나 명령 프롬프트에서 skel2d.exe가 있는 폴더로 이동하거나 전체 경로로 실행합니다.)

10.1 자주 쓰는 명령

명령하는 일
skel2d new hero.skel.json --name hero빈 문서 생성 (--force: 덮어쓰기). root 본만 있습니다.
skel2d info FILE본, 슬롯, 애니메이션 목록(이름, 길이).
skel2d validate FILE{"valid":true} 또는 모든 문제 목록.
skel2d pose FILE --anim wave --time 0.5월드 좌표의 본 변환 숫자. --skin, --physics none|simulate 가능.
skel2d render FILE -o out.png셋업 포즈 PNG. --anim A --time T 한 프레임, --anim A --frames 8 가로 8프레임 스트립, --no-bones, --width/--height, --zoom, --center X,Y, --track NAME[@T], --skin.
skel2d gif FILE -o out.gif ...GIF 내보내기 (8장). skel2d gif --help로 전체 옵션.
skel2d apply FILE --ops '[...]'편집 연산 묶음을 원자적으로 적용. 하나라도 실패하면 전부 취소. --dry-run은 검사만. 연산 파일(ops.json)이나 -(표준입력)도 됩니다.
skel2d schema ops연산의 JSON Schema (document, rig, layers, tracks도 가능).
skel2d image-info img.png --grid g.png그림 크기·보이는 영역 분석, 좌표 격자 이미지 생성.
skel2d rig img.png --spec spec.json -o out.skel.json그림 한 장과 관절 좌표(픽셀)로 본·메쉬·가중치를 자동 생성. layers.json 목록도 받습니다.
skel2d psd 파일.psd -o partsPSD를 부위별 PNG와 layers.json으로 분리.
skel2d slice sheet.png -o parts부품 시트를 읽는 순서대로 PNG 한 장씩 자름. --key 00ff00으로 배경색 제거.
skel2d key, skel2d crop크로마키 배경 제거, 지정 영역 잘라내기.

예:

skel2d info examples\skins\skins.skel.json
skel2d render examples\skins\skins.skel.json -o strip.png --anim walk --frames 4 --skin knight
skel2d apply hero.skel.json --ops "[{\"op\":\"key_bone\",\"animation\":\"wave\",\"bone\":\"arm_l\",\"time\":0.5,\"rotate\":110}]"

PowerShell에서는 따옴표가 까다로우니 연산을 ops.json 파일에 쓰고 skel2d apply hero.skel.json ops.json으로 적용하는 것이 편합니다.

11.2 문제 해결 (FAQ)

Q. 이미지가 안 보이고 "이미지가 없습니다: ..."가 떠요 (또는 사각형 자리표시만 보여요).

그림 경로는 문서 파일 기준 상대 경로로 저장됩니다. 문서만 다른 폴더로 옮기면 경로가 어긋납니다. 해결: 그림 파일을 문서와의 상대 위치가 원래대로 되도록 같이 옮기거나, 2단계에서 슬롯의 이미지 카드 더 보기 > 이미지 파일 교체...로 파일을 다시 지정하세요. 새 문서는 그림을 불러온 뒤 그림이 있는 폴더 근처에 저장하는 것이 안전합니다. 명령줄 skel2d render 결과의 missing_images에서도 확인할 수 있습니다.

Q. 어디에 저장되나요?

다른 이름으로 저장...에서 고른 위치입니다. 에디터는 자동 저장하지 않으니 Ctrl+S를 자주 누르세요. 제목 없음 상태에서 Ctrl+S를 누르면 위치를 묻습니다. GIF는 저장할 파일 칸의 경로(기본은 문서 폴더)에 저장됩니다. 에디터 설정(언어, UI 크기, GIF 설정 등)은 사용자 설정 폴더에 따로 기억됩니다.

Q. 예제를 연 채 GIF를 내보냈더니 examples 폴더에 파일이 생겼어요.

기본 저장 위치가 문서 폴더이기 때문입니다. 찾아보기…로 다른 폴더를 고르세요.

Q. 메쉬를 만들었는데 가중치 단계에서 "먼저 메쉬로 만드세요"가 나와요.

다른 이미지를 골랐거나 아직 그림(리전) 상태입니다. 3단계에서 메쉬 만들기를 하세요.

Q. 팔을 돌렸더니 옆 다리나 몸이 같이 따라와요.

그 메쉬에 해당 본이 없거나 가중치가 퍼져 있습니다. 다리·몸에도 본을 두고(1단계), 4단계에서 자동으로 가중치 넣기를 다시 한 뒤 브러시로 문제 부위에서 해당 본을 빼세요 (Ctrl+드래그).

Q. 시간 막대를 옮겼더니 "키를 찍지 않은 변경 N개를 버렸습니다"가 떠요.

자동 키가 꺼져 있었습니다. 값을 바꾼 뒤 K나 키 버튼으로 키를 찍고 나서 이동하세요. 자동 키를 켜 두면 생기지 않습니다.

Q. 버튼이 흐리게 눌리지 않아요.

조건이 안 맞는 버튼은 흐리게 표시되고 바로 아래에 이유가 적혀 있습니다 (예: "가중치 편집은 셋업 포즈에서 실행합니다" - 5단계에서는 가중치 편집 불가, 1~4단계로 돌아가세요).

Q. 시간 막대를 움직이면 물리 본이 이상하게 튀어요.

물리는 시간 순서대로 계산됩니다. 점프하듯 시간을 건너뛰면 리셋(Shift+R)으로 현재 포즈에서 다시 시작하세요. 컷 전환에는 5단계에서 리셋 키를 찍습니다.

Q. GIF 가장자리가 지저분해요 (흰 테두리).

투명 배경 GIF는 부드러운 가장자리가 배경색과 섞입니다. 배경을 GIF를 올릴 페이지 색에 맞추세요 (8.2). 가장자리가 더 단단하길 원하면 알파 임계값을 올립니다.

Q. GIF가 너무 커요.

크기 줄이기(픽셀 크기에 맞추기), FPS 20~25, 색 수 줄이기, 디더링 끄기, 월드 영역으로 자르기로 여백 줄이기를 시도하세요.

Q. Windows가 실행을 막아요.

1.4를 보세요.

Q. 외부에서 파일이 바뀌었다는 창이 떠요.

명령줄이나 AI가 같은 파일을 고쳤습니다. 에디터에서 저장하지 않은 변경이 있어서 묻는 것입니다. 다시 불러오기 (내 변경 버리기) 또는 내 변경 유지를 고르세요.
