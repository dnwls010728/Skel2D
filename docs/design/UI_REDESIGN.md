# UI/UX 재개발 설계

작성: 2026-10-31. 사용자 결정: 기존 편집기들의 인상에 기대지 않고 접근성·사용성·시인성·가독성 위주로 다시 만든다. 게임에서는 자체 런타임으로 재생한다.

## 1. 해결할 문제 (사용자가 겪은 것)
- 메쉬·가중치를 추가·편집할 수 있는지, 지금 되는 상태인지 화면만 봐서는 모른다.
- 슬롯 하나에 이미지를 여러 장 넣는 방법이 에디터에 없다(`Attachment` 콤보로 고르기만 가능).
- 립싱크·눈 깜빡임 생성기를 봐도 무엇인지, 어떻게 쓰는지 모른다.
- 도구와 패널이 전문가용 축약 표현이라 어디서 시작할지 모른다.

## 2. 원칙
1. **작업 순서가 화면에 보인다.** 어떤 도구를 고르는가가 아니라 무슨 작업을 하는가로 화면이 바뀐다.
2. **상태를 글로 말한다.** "이 이미지는 아직 메쉬가 아닙니다", "가중치 없음: 본 upper를 100% 따라감".
3. **안 되는 이유를 숨기지 않는다.** 비활성 버튼 옆이나 아래에 이유와 해결 버튼을 항상 보여 준다. 숨기거나 툴팁에만 넣지 않는다.
4. **아이콘만 있는 버튼 금지.** 주요 동작은 글자 라벨이 있다. 호버해야만 뜻을 아는 UI 금지.
5. **색만으로 의미를 전달하지 않는다.** 키 상태는 색 + 모양 + 글자.
6. **용어는 쉬운 말로**(§5). 내부 op 이름은 그대로 둔다.
7. 모든 버튼은 op 또는 미리보기 API만 만든다(`NEXT_PHASE.md` §0.1, §4.1 유지). AI 동등성은 그대로다.

## 3. 시각 기준
- 본문 글자 14pt 이상, 보조 글자 12pt 이상. 클릭 영역 높이 28px 이상.
- 글자/배경 대비 4.5:1 이상(비활성 포함 보조 글자 3:1 이상). `theme.rs` 상수로 관리하고 대비를 계산하는 단위 테스트를 둔다.
- 포커스 표시가 보인다. 키보드 탭 이동 유지.
- View 메뉴에 UI 크기 100/125/150%(설정 저장).
- 언어를 섞지 않는다. 시작 상태바 문구까지 현재 언어로 표시한다.

## 4. 화면 구조
```
┌ 메뉴 ───────────────────────────────────────────────────────┐
│ [1 뼈대] [2 이미지] [3 메쉬] [4 가중치] [5 애니메이션]   실행취소 다시실행 │  ← 작업 단계 바
├───────┬──────────────────────────────────┬────────────────┤
│ 도구   │  뷰포트                           │ 이 단계의 목록    │
│ (단계별 │  상단: 안내 한 줄 "무엇을 할 수 있나" │ ─────────────── │
│ 글자 포함)│                                 │ 선택 항목 패널     │
├───────┴──────────────────────────────────┴────────────────┤
│ (5단계만) 타임라인                                              │
├──────────────────────────────────────────────────────────┤
│ 상태바: 선택 항목 · 결과 메시지 · 현재 단계 단축키                    │
└──────────────────────────────────────────────────────────┘
```
현재의 왼쪽 도구 레일, SETUP/ANIMATE 스위치, 탭(Tree/Order/제약/Anims/Skins)을 이 구조로 대체한다. 내부 `Tool`과 `playback.anim`은 재사용한다: 1~4단계는 셋업(`anim=None`), 5단계는 애니메이션. 단계 전환 시 마지막 애니메이션을 복원한다. 1~5 숫자키로 전환한다(기존 단일 문자 단축키는 도구 라벨에 표시하고 유지).

### 1 뼈대
- 도구: 선택, 새 본, 이동, 회전, 크기.
- 목록: 본 트리. **root는 항상 맨 위에 있고 삭제·이름 변경·이동 불가**(잠금 표시와 이유 문구). 새 본은 선택 본 아래, 선택이 없으면 root 아래. 슬롯과 그 이미지는 본 아래에 기본으로 보인다(5단계와 같음). 슬롯을 누르면 단계를 바꾸지 않고 슬롯 패널이 열린다. 목록 머리글의 "슬롯" 토글(편집기 설정으로 저장)로 끌 수 있으며, 끄면 본 행에 "슬롯 N개"만 남는다. 목록과 속성 패널 사이 구분선은 끌어서 조절하고 높이를 저장한다(기본은 목록이 더 높다).
- 패널: 본 값. 그룹 "자동으로 따라가기(IK)", "흔들림(물리)"에 추가 버튼과 설명 한 줄. 제약 실행 순서는 이 단계의 "제약 순서" 하위 목록.

### 2 이미지
- 목록: 슬롯(그리기 순서 그대로, 위가 앞). 슬롯 행에 현재 이미지 썸네일. 드래그로 순서 변경. 맨 위 큰 버튼 [이미지 불러오기](PNG/PSD), 드롭 안내.
- 슬롯 패널의 핵심 = **이미지 카드 목록**: 슬롯의 모든 이미지를 썸네일 + 이름 + 종류(그림/메쉬/링크드) + [표시 중] 라디오로 보여 준다.
  - **[+ 이미지 추가]**: 파일 선택(여러 장). 같은 슬롯에 새 어태치먼트로 추가한다(`set_attachment`). 뷰포트 드롭 시 슬롯이 선택돼 있으면 "이 슬롯에 추가 / 새 슬롯" 선택.
  - 카드 메뉴: 이름 변경, 이미지 교체, 삭제, [메쉬로 변환](3단계로 이동).
  - 위치·회전·크기는 선택 이미지의 값.
- 그룹 "의상(스킨)": 스킨 목록·미리보기 눈 아이콘·슬롯 이미지를 스킨에 넣기. 스킨 없을 때 뜻을 한 줄로 설명.

### 3 메쉬
- 대상 표시 줄: "슬롯 ▸ 이미지". 대상이 없거나 그림이면 패널이 곧 안내다:
  - 선택 없음: "왼쪽에서 이미지를 고르세요" + 메쉬가 될 수 있는 이미지 목록(클릭 선택).
  - 그림(리전): "아직 메쉬가 아닙니다. 메쉬로 바꾸면 이미지를 구부릴 수 있습니다." [메쉬 만들기] → 기존 실시간 미리보기 대화상자.
  - 링크드 메쉬: "부모 메쉬의 모양을 씁니다" + [부모로 이동].
- 메쉬이면: 정점/삼각형 수, 모드 버튼에 설명 포함: **이동**(정점 끌기), **추가**(클릭해 정점 추가), **삭제**(클릭해 삭제), **선**(정점끼리 끌어 접히는 선 지정). 뷰포트 안내 줄도 모드 따라 바뀐다. 동작 후 "정점 1개 추가됨 · Ctrl+Z 취소" 메시지.
- [다시 만들기] [자동 정점 추가] [링크드 메쉬 만들기]. UV 리셋 2종은 "고급" 접기.
- 떠 있는 `mesh_tool_window`를 패널로 옮긴다.

### 4 가중치
- 대상 표시는 3단계와 같다. 메쉬가 아니면 "먼저 메쉬로 바꾸세요" + [3단계로 이동 후 만들기].
- 상태 한 줄: "가중치 없음: 전체가 본 upper를 따라감" / "본 3개에 묶임".
- 큰 버튼 **[자동으로 가중치 넣기]**(이미지 기준, 대안 거리 기준) 최상단. 묶인 본 목록: 막대 + % 숫자 + 잠금 라벨. 행 클릭 = 칠할 본(뷰포트 히트맵, 범례 표시).
- 브러시 추가/빼기/지정 + 반경·강도 슬라이더에 값 표시. 뒤틀림 확인: "본을 돌려 보기"(Alt 드래그)를 문구로 설명.
- 기타(스무스·정리·교환·미러·전송)는 설명 있는 버튼 목록. 떠 있는 창·`weights_panel`을 패널로 옮긴다.

### 5 애니메이션
- 애니메이션 목록(없으면 "새 애니메이션"을 큰 버튼으로). 타임라인 표시.
- 키 버튼은 색 + 모양 + 라벨: ◆ 키 있음 / ◇ 키 없음 / ● 변경됨(미저장).
- **이미지 바꾸기 = 눈 깜빡임·립싱크의 전부.** 슬롯을 선택하면 패널에 이미지 카드 줄이 보이고, 썸네일을 클릭하면 현재 시간에 그 이미지로 바뀌는 키가 생긴다(`key_slot`, 숨기기 카드 포함). 패널 안내: "눈 깜빡임: 눈 슬롯에 '뜬 눈/감은 눈' 이미지를 넣고, 감을 시간에 감은 눈을 누르세요".
- **기존 `generate_section`(눈 깜빡임·립싱크 생성기)은 에디터에서 제거한다.** `generate_blink`/`generate_lipsync` op는 AI용으로 코어에 유지한다.
- 레이어 미리보기는 "함께 재생할 애니메이션"으로 라벨 변경. 물리 컨트롤(일시정지, 리셋, 끄기)은 글자 라벨 유지.

## 5. 용어 (UI 문구, 영어/한국어)
| 내부 | 영어 | 한국어 |
|---|---|---|
| attachment | Image | 이미지 |
| region | Picture | 그림 |
| slot | Slot | 슬롯 |
| setup / animate | Build / Animate | 만들기 / 애니메이션 |
| weights | Weights | 가중치 |
| IK | Follow target (IK) | 목표 따라가기 (IK) |
| physics | Jiggle (physics) | 흔들림 (물리) |
| skin | Outfit (skin) | 의상 (스킨) |
| linked mesh | Shared mesh | 공유 메쉬 |
| hull | Outline | 외곽선 |
| draw order | Front to back | 앞뒤 순서 |

다른 제품의 이름은 화면 문구, 문서, 코드 주석 어디에도 쓰지 않는다. 동작을 설명할 때는 Skel2D가 무엇을 하는지와 이유만 적고 다른 제품과 비교하지 않는다.

## 6. 시작 경험
빈 문서(root만 있음)에서 뷰포트 중앙에 단계 안내: "1. 이미지 불러오기 2. 뼈대 그리기 3. 메쉬 4. 가중치 5. 애니메이션"과 [이미지 불러오기] [예제 열기]. F1 도움말은 단계별로 다시 쓴다.
